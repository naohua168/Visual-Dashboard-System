# Visual Dashboard System —— 可选：手动指定 Python 解释器所在「目录」
#
# 用法：在下面写一行目录（只要目录，不要写 python.exe / pythonw.exe），例如：
#       C:\Users\yourname\.conda\envs\visual-dashboard-system
#       C:\Python312
#
# 解释器选择优先级（2026-09-30 口径）：
#   ① 本文件里填的目录（填了就优先用，最高优先级）
#   ② 内置运行时 runtime\python（交付包自带，解压即用）
#   ③ %USERPROFILE%\.conda\envs\visual-dashboard-system（Conda 默认位置）
#   ④ 系统 PATH 里的 python / pythonw
#
# 说明：
#   · 本文件留空（或只剩 # 开头的注释）= 不指定，直接从第 ② 步开始自动探测
#   · 填了但路径无效 → 控制台打印一条警告，然后继续从第 ② 步探测（不会卡死）
#   · 以 # 开头的行是注释；只有第一行「有效内容」会被读取
#   · 改完保存即可生效，不需要改任何 .bat
#   · 图形入口（启动系统.bat）读的是同目录下的 pythonw.exe，命令行入口（run_all.bat）读 python.exe
