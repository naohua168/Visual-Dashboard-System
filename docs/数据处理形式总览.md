# 数据处理形式总览

> 版本：v2.0 | 更新：2026-11-02
> 本文档穷举系统**处理数据的每一种形式**：每类数据源怎么进来、金额怎么换算、时间怎么切、哪些行会被丢、客户怎么归到母公司/销售、名字怎么归一、名单怎么维护、最后输出什么。
> 相邻文档：[数据清洗展示逻辑.md](数据清洗展示逻辑.md)（逐页展示逻辑）、[字段映射.md](字段映射.md)（列名对照）、[数据系统设计.md](数据系统设计.md)（结构/配置）。

---

## 0. 一句话概括

> **原始 Excel 有 8 类来源、4 种金额单位、5 个时间窗口、5 类行级过滤、8 种归属/归拢方式**；
> 清洗后统一成 5 列标准表（事业部/金额/客户/法人主体/日期，单位**元**），再叠加销售与母公司两列，最后渲染 6 页 + 数据总表。

```
data/raw 8 类来源
   │  过滤（白名单 / 内部交易 / 期初 / 保留取值 / 日期）
   ▼
5 列标准表（元）── 三路输出：月 / 季度累计 / 当年累计
   │  归属（8 种形式）→ +销售 +母公司
   ▼
7 列销售表 ── 渲染 ── 6 页 HTML + 16 sheet 总表
```

## 1. 数据来源形式（8 类 + 3 类辅助）

| # | 来源 | 文件 | 期间语义 | 金额单位 | 事业部 | 法人主体 | 过白名单 |
|---|------|------|----------|----------|--------|----------|----------|
| 1 | 财务端收入 | `data/raw/财务端数据/收入.xlsx` | 当月 | 元（不含税金额） | 源表「成本中心」映射 | 源表「公司」 | ✅ |
| 2 | 财务端回款 | `data/raw/财务端数据/回款.xlsx` | 当月 | 元（应收金额） | 源表「成本中心」映射 | 源表「公司/收款公司」 | ✅ |
| 3 | 广东公司 | `data/raw/财务端数据/广东公司.xlsx`（收入/回款两 Sheet） | 累计简表 | **万元 ×10000** | **固定=检测** | 整表=广东汽车检测中心 | ❌ |
| 4 | 湖南公司 | `data/raw/财务端数据/湖南公司.xlsx`（两 Sheet） | 累计简表 | **万元 ×10000** | **固定=信息** | 整表=中汽院（湖南） | ❌ |
| 5 | 南方韶关 | `data/raw/财务端数据/南方韶关.xlsx`（两 Sheet） | 累计简表 | **元 ×1** | **固定=检测** | 整表=南方（韶关） | ❌ |
| 6 | 运营端收入 | `data/raw/运营端数据/收入.xls` | 当年累计（含"1-N月"） | 元 | 源表「事业部」 | 源表「核算单位/法人主体/所属单位」 | ❌ |
| 7 | 运营端回款 | `data/raw/运营端数据/回款.xls` | 当年累计 | 元 | 源表「事业部」 | 同上 | ❌ |
| 8 | 往年基线 | `data/raw/往年收入数据/往年年收入.xlsx` / `往年回款数据/往年年回款.xlsx` | 去年整年（月份范围可配） | 元 | 源表「事业部」（全称→简称） | 源表（简称→全称） | ❌ |

辅助（不改数据，只做判定）：

| # | 文件 | 作用 | 影响谁 |
|---|------|------|--------|
| A | `data/raw/客户名单/客户名单.xlsx` | 财务端白名单 | 只有来源 1、2 的行会被筛 |
| B | `data/sheets/手动维护/` 6 张指标表 | 目标金额（万元） | 6 页的目标/达成度 |
| C | `data/mappings/部门事业部映射/部门事业部映射.json` | 事业部全称→简称、内部交易公司排除名单 | 所有来源 |

> 实现：来源 1~5 见 `engine/income_payment/financial.py`，来源 6~7 见 `operations.py`，来源 8 见 `engine/yearly_baseline/`。

## 2. 金额单位形式（4 种）

| 形式 | 出现在哪 | 换算 | 配置项 |
|------|----------|------|--------|
| **元** | 财务端主表、运营端、往年基线、南方韶关 | 原样（×1） | `金额乘数 = 1` 或不配 |
| **万元** | 广东公司、湖南公司 | **×10000 → 元** | `金额乘数 = 10000` |
| **万元** | 6 张指标表 | 渲染层**÷10000** 展示为万元 | 指标表本身不换算 |
| **万元** | 配置编辑器「KPI指标」填的值 | 覆盖 KPI 卡片时按万元 | 展示用 |

- `金额乘数` 支持两种写法：**数值**（该来源所有 Sheet 相同）或**字典**（按 Sheet 分别配，如 `{"收入": 1, "回款": 10000}`）。**代码里不写死 ×10000**。
- 统一出口：清洗输出 `输出.金额单位 = "元"`；渲染层 `_add_wan()` ÷10000 → 万元 → `fmt_wan()` 千分位、`.0f` 无小数。

## 3. 时间口径形式（5 个窗口 + 2 种结算语义）

| 窗口 | 配置键（`时间范围`） | 谁在用 |
|------|---------------------|--------|
| 年度累计 | `年度累计` | 数据总览 / 年度达成 / 销售达成 / 年度同比 |
| 月度 | `月度数据` | 月度达成（**只用财务端当月**） |
| 季度累计 | `季度累计筛选` | 季度达成 |
| 年基线 | `年基线数据`（年份 + 月份范围） | Phase 0 清洗 + 年度同比 |
| 回款双日期 | `日期字段组 = ["日期","收款日期"]` | 财务端回款：**两个日期都要落在窗口内**才收录 |

结算模式（`时间范围.结算模式.值`）决定**累计口径是否叠加财务端**：

- `常规`（当前）：当年累计 / 季度累计 = 财务端（当月）+ 运营端
- `月底结算`：运营端已是完整年度累计（含当月）→ 累计**只用运营端**，避免当月重复计算
- **月数据始终只用财务端当月**，两种模式都一样

## 4. 行级过滤形式（5 类）

| # | 过滤 | 触发条件 | 后果 | 配置位置 |
|---|------|----------|------|----------|
| 1 | **客户白名单** | 来源 `过客户白名单=true`（只有财务端收入/回款） | 名单外的客户**整行丢弃**，命中后客户名替换为名单里的写法 | `data/raw/客户名单/客户名单.xlsx` |
| 2 | **内部交易** | 运营端「是否属于内部单位/内部款项」= 是 等；或客户在 `excluded_internal_companies` 名单里 | 行级剔除（广东自有归入扫描里升级为**公司级**） | `业务规则.json → 广东自有归入.内部交易标记值` + 映射 JSON |
| 3 | **期初剔除** | 收入表「初始化」列 = `√`（期初/历史单据迁移） | 整行剔除；回款表无此字段 | 「字段映射」sheet → 排除标记列/值 |
| 4 | **保留取值** | 收入：单据状态=已审核、委托类型=外部结算/委托外部结算；回款：单据状态=已收款 | **只保留命中值**，未命中的行丢弃 | 「字段映射」sheet → 保留取值 |
| 5 | **日期范围** | 所有来源 | 窗口外的行剔除 | `时间范围` |

> 白名单丢弃会落到 `output/数据校验/数据质量摘要_*.xlsx` 的「丢弃汇总/未匹配明细」，运行结束打印「白名单未匹配丢弃: N 行 / X 万元」。

## 5. 客户归属形式（8 种）

### 5.1 精确配置（主形式）
`客户销售归属.json` 的结构：`{母公司: {子公司: {指标: {部门: {销售: 比例}}}}}`。
- 指标取 `收入` / `回款`；部门取 检测/信息/能源/海外；比例 0~1（金额按比例拆给多个销售）
- 编辑入口只有一个：`config/配置编辑器.xlsx → 销售归属`（每次运行按 Excel 重写 JSON）
- 当前规模：**109 母公司 / 600 子公司**

### 5.2 父组名自带销售（`母公司·销售`）
- 写法：母公司列直接写 `科技公司·王海龙`、`科技公司·李巍`（当前 38 / 98 家子公司）
- 分隔符**任意**（`· - － / 、 :` 空格…甚至漏打），`name_key.normalize_known_parent()` 统一归一
- 这类父组**不再写进** `_销售拆分.客户矩阵`（否则会拼成 `科技公司·王海龙·王海龙`）
- 指标表客户列、展示规则的「优先展示/客户筛选」同样容错

### 5.3 旧拆分机制（`_销售拆分.客户矩阵`）
- 父组名**不带销售**时，用 `客户销售归属.json → _销售拆分.客户矩阵` 列出要按销售拆行的母公司；`split_key_parts()` / `_sub_to_sales_key()` 处理 `母公司·销售` 键
- 现状：当前配置不使用（父组名已自带销售），但机制保留，`tests/test_split_key_normalize.py`、`test_mock_page_data.py` 仍覆盖

### 5.4 广东自有客户 · 预扫描自动归入
- 脚本：`scripts/scan_gd_owned.py`（流水线**第 1 步**，排在配置同步前，`--write` 直接写 Excel）
- 候选来源：**运营端 收入/回款 .xls + 财务端「广东公司.xlsx」（两 Sheet）**（2026-11-02 起；此前只扫运营端）
- 判定：法人=广东汽车检测中心（广东公司整表按配置法人）→ **公司级**无任何销售归属 → 公司级排除内部交易 → 黑名单（合计/无/内部…+3 个法人自身名）→ 名字 ≥5 字
- 写入：每家 **4 行**（检测/信息/能源/海外），指标 `收入/回款`，销售 **黎国键**，比例 1，追加在表末
- 防重复：`data/mappings/广东自有/已自动归入.json` 记录"曾自动归入"，**人工从 Excel 删掉后不会再自动加回**

### 5.5 多组配置 · 按法人主体分流（广东自有 ↔ 零部件）
- 现象：同一子公司在多个父组下都配了（当前 14 家同时挂「广东自有客户」与「零部件客户」）
- 规则（`processors/data_utils/consolidate.py::filter_gd_by_legal`，只对这批"多组"子公司生效）：
  - 法人 = 广东汽车检测中心 → 客户名保持原样（归「广东自有客户」）
  - 法人 ≠ 广东 → 客户名**改写成它的"其他父组"**（优先「零部件客户」，否则第一个非广东自有组）→ 金额不丢，进对应父组
- **只挂广东自有组、别处没有的子公司不做判定，全部保留**

### 5.6 比亚迪两父组 · 按法人主体定唯一归属
- 适用：**同时**挂在「比亚迪汽车工业有限公司」与「比亚迪电池」两个父组下的子公司（配置驱动 `_byd_multi_subs()`）
- 渲染层（`filter_byd_by_legal`）：法人=广东 → 客户名改为「比亚迪汽车工业有限公司」；其他 → 「比亚迪电池」
- 销售引擎（`_apply_byd_sales_override`）：广东主体 → **黄浩浩**；其他 → **周涵林**
- 只挂单边的保持原归属不动

### 5.7 南方韶关 · 无销售归属则归拢母公司行
- 触发（`filter_sg_by_legal`）：`法人主体 = 南方（韶关）…` **且** 该行在「该口径（收入/回款）+ 该部门」下查不到销售 → 客户名改为母公司 **`南方韶关`**
- 生效页面：**年度 / 月度 / 季度达成**（`_consolidate_customers(df, "收入"/"回款")`）；数据总览、年度同比、销售达成**不归拢**
- 有销售归属的韶关行 → 保持原客户行走销售；法人非韶关 → 不动
- 抽屉一致性：`_SG_CHILDREN_SEEN` 记录被归入的客户名，子行金额**只统计法人=韶关的行**（子行合计 = 矩阵母公司行）

### 5.8 未匹配 → 待确认
- 客户在任何父组里都查不到 → 拆分结果 `销售 = 待确认`、`母公司 = 空`，销售达成页可点开「待确认」弹窗
- 广东自有门控（2026-09-21）：某客户配在「广东自有客户」组、但这行法人不是广东汽车检测中心 → 也按"待确认"处理，避免韶关业绩算给广东自有销售

## 6. 客户名归一形式（4 层）

| 层 | 规则 | 代码 |
|----|------|------|
| 匹配键 | NFKC（全角→半角）+ 去全部空白/零宽字符 + 大写；**不删「（深圳）」「有限公司」等内容** | `engine/core/name_key.py::match_key` |
| 拆分键 | `母公司·销售` 的分隔符任意（含漏打），统一归一 | `split_key_parts` / `normalize_known_parent` / `SPLIT_SEP` |
| 后缀兜底 | 1:1 匹配不上时按去掉 `有限公司/科技/股份有限公司/有限责任公司/公司` 再匹配 | `_consolidate_customers._strip` |
| 显示名 | 以归属表/名单里**先出现**的写法为准，匹配不影响展示 | `KeyedLookup` |

## 7. 客户名单维护形式（2 种）

| 形式 | 操作 | 说明 |
|------|------|------|
| **手工编辑** | 直接改 `data/raw/客户名单/客户名单.xlsx`（单列「客户」） | 唯一编辑层；`data/mappings/客户名单/客户名单.json` 每次运行被重写生成 |
| **自动同步** | 跑流水线（配置同步步骤）自动执行 `scripts/sync_customer_list.py` | **只加不删**、无新增不碰文件、有新增先备份 `logs/名单同步/`（留 5 份）、过滤法人自身名/占位行、按匹配键去重、文件被占用则跳过不中断 |

- 触发点：`scripts/editor/cli.py` 写完销售归属 JSON 之后
- **前置保证（2026-11-02）**：只要本次运行包含数据处理步骤（年基线/清洗/拆分/渲染），`bin/runner.py` 与 `bin/main.py` 会**自动把「配置预扫描 + 配置同步（含名单同步）」插到最前面** —— 分步跑 `--step=clean`、续跑 `--from=split` 也一样；`--no-config` 时除外（显式不碰配置）
- 单独运行：`python scripts/sync_customer_list.py [--dry-run] [--excel]`
- 排除项：`业务规则.json → 客户名单同步.排除父组 / 排除客户`
- **只影响财务端收入/回款两张主表**；广东/湖南/南方韶关、运营端、年基线一律不过白名单

## 8. 输出形式（5 类）

| 输出 | 位置 | 内容 |
|------|------|------|
| 清洗输出 10 个目录 | `data/sheets/系统数据清理/` | 往年收入/回款、月收入/回款、当年累计收入/回款、季度累计收入/回款、销售收入/回款（5 列或 7 列，单位元） |
| 看板 | `output/看板/<年>/<月>/看板_YYYYMMDD.html` | 6 页：数据总览 / 年度达成 / 月度达成 / 季度达成 / 销售达成 / 年度同比 |
| 数据总表 | `output/数据/<年>/<月>/data_YYYYMMDD.xlsx` | 16 个 sheet（与 `data/sheets/` 目录同名 + 6 张指标表） |
| 销售完成度（按需） | `output/销售完成度/<年>/<月>/销售完成度汇总_YYYYMMDD.xlsx` | 销售 × 4 部门 实际/指标（元）；`python bin/app.py report` |
| 数据校验 | `output/数据校验/<年>/<月>/数据质量摘要_YYYYMMDD_HHMMSS.xlsx` | 概览 / 问题清单 / 丢弃汇总 / 未匹配明细 |

> 四类产物均按**年月分类**：`output/<类别>/<年>/<月>/文件`（2026-11-06 起）。

## 9. 一页速查

| 我要确认… | 答案 |
|-----------|------|
| 这行钱算不算 | 先看来源：财务端两主表过白名单，其余全量 |
| 金额差 1 万倍 | 广东/湖南是万元（×10000），南方韶关是元（×1） |
| 事业部为什么固定 | 广东=检测、湖南=信息、南方韶关=检测（源表无部门列） |
| 为什么客户只显示一部分 | 白名单丢弃（看数据校验报告「未匹配明细」） |
| 为什么某客户跑到别的父组 | 多组配置按法人分流（广东自有 ↔ 零部件） |
| 为什么韶关没有销售 | 法人=韶关且无销售归属 → 归拢到「南方韶关」母公司行（销售达成页显示待确认） |
| 为什么科技公司有两位销售 | 父组名自带销售：`科技公司·王海龙` / `科技公司·李巍` |
| 新客户怎么进看板 | ① 销售归属加客户 → ② 自动进客户名单 → ③ 白名单放行 → ④ 归属命中才有销售 |
| 名单被谁改了 | 配置同步自动补（只加不删），备份在 `logs/名单同步/` |
