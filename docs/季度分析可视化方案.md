## 三、各区域详细设计

### [A] KPI 指标卡片行

**目的**: 一眼掌握核心数字和趋势

| 卡片 | 主数值 | 辅助信息 | 视觉强调 |
|------|--------|----------|----------|
| 年累计收入 | 44,046 万 | — | 蓝色主调 |
| 年累计回款 | 56,585 万 | — | 金色主调 |
| Q2 收入 | 44,046 万 | 占年比 100% | 绿色箭头↑ |
| Q2 回款 | 56,585 万 | 占年比 100% | 绿色箭头↑ |

**设计要点**：
- 使用 `grid-template-columns: repeat(4, 1fr)` 四等分
- 卡片悬停微动效 (`transform: translateY(-2px)`)
- 环比箭头用颜色编码：绿↑红↓灰→

---

### [B] 事业部环形图

**数据源**:

| 事业部 | 收入(万) | 占比 | 回款(万) | 回款占比 |
|--------|---------|------|---------|---------|
| 检测 | 29,923 | 67.9% | 34,551 | 61.1% |
| 信息 | 7,093 | 16.1% | 14,830 | 26.2% |
| 能源 | 6,757 | 15.3% | 6,668 | 11.8% |
| 海外 | 273 | 0.6% | 536 | 0.9% |

**图表选择**: 环形图 (Doughnut Chart)

**理由**:
- ✅ 占比关系清晰直观
- ✅ 中心可放置总额数字
- ✅ 适合 2~5 个分类
- ⚠️ 检测占比过高(68%)，需考虑拆分子类或备注说明

**配色方案**:
```
检测: #2563eb (蓝) — 主业
信息: #059669 (绿) — 成长型
能源: #d97706 (橙) — 稳健型
海外: #dc2626 (红) — 拓展中
```

**交互设计**:
- 悬停显示具体数值和百分比
- 点击切换「收入/回款」视图
- 中心数字动态更新

---

### [C] 事业部分组柱状图

**目的**: 同一维度下收入 vs 回款的直接对比

**图表类型**: 分组柱状图 (Grouped Bar Chart)

**X轴**: 4 个事业部  
**Y轴**: 金额(万元)  
**分组**: 收入(蓝) / 回款(金)

**关键洞察标注**:
- 信息事业部：回款 > 收入 109%（超收最多）
- 广汽集团：回款率仅 18.5%（需关注）
- 上汽通用五菱：回款率 470%（历史回款集中到账）

**增强元素**:
- 在柱顶标注完成率百分比
- 用虚线连接同事业部的收/回款柱
- 差额为正的用绿色底纹，负的用红色

---

### [E] 客户回款率热力矩阵

**目的**: 快速识别回款风险客户

**结构**:
- 行: 事业部 (4)
- 列: Top 客户 (按收入排序取前15)
- 单元格颜色: 回款率色阶

**色阶定义**:
```
深绿 ≥120%  (超收)    #059669
浅绿 95-119% (健康)    #34d399
黄   70-94%  (正常)    #fbbf24
橙   50-69%  (预警)    #f97316
红   <50%    (风险)    #dc2626
灰   无数据            #e2e8f0
```

**交互**:
- 悬停显示精确数值
- 点击单元格跳转到客户详情
- 支持按事业部/回款率排序

### [F] 详细数据表格

**列设计**:

| 列名 | 类型 | 对齐 | 说明 |
|------|------|------|------|
| # | 序号 | 居中 | Top-N 排名徽章 |
| 客户名称 | 文本 | 左对齐 | 可截断长名 |
| 事业部 | 标签 | 居中 | 彩色标签 |
| 累计收入 | 数字 | 右对齐 | 万元，千分位 |
| 累计回款 | 数字 | 右对齐 | 万元，千分位 |
| 差额 | 数字 | 右对齐 | 正绿负红 |
| 回款率 | 徽章 | 居中 | 四色等级 |
| 趋势 | 图标 | 居中 | ↑↓→ (需历史数据) |

**功能**:
- 表头点击排序
- 事业部筛选下拉
- 回款率范围筛选
- 导出 CSV 按钮

## 五、技术实现建议

### Chart.js 配置要点

```javascript
// 1. 全局主题配置
Chart.defaults.color = '#64748b';
Chart.defaults.font.family = 'Inter, system-ui';

// 2. 环形图 - 事业部占比
{
  type: 'doughnut',
  data: {
    labels: ['检测', '信息', '能源', '海外'],
    datasets: [{
      data: [29923, 7093, 6757, 273],
      backgroundColor: ['#2563eb', '#059669', '#d97706', '#dc2626'],
      borderWidth: 0,
      hoverOffset: 8
    }]
  },
  options: {
    cutout: '65%',        // 环形宽度
    plugins: {
      legend: { position: 'right' }
    }
  }
}

// 3. 分组柱状图 - 事业部对比
{
  type: 'bar',
  data: {
    labels: ['检测', '信息', '能源', '海外'],
    datasets: [
      { label: '收入', data: [...], backgroundColor: '#2563eb' },
      { label: '回款', data: [...], backgroundColor: '#f59e0b' }
    ]
  },
  options: {
    scales: { y: { beginAtZero: true } }
  }
}

// 4. 帕累托组合图 - Top客户
{
  type: 'bar',  // 主条形
  data: {
    datasets: [
      {
        label: '收入(万元)',
        data: [...],
        backgroundColor: (ctx) => rateColor(ctx.raw.paymentRate),
        order: 2
      },
      {
        type: 'line',  // 累计占比折线
        label: '累计占比%',
        data: [...],
        borderColor: '#dc2626',
        yAxisID: 'y1',
        order: 1
      }
    ]
  },
  options: {
    scales: {
      y: { position: 'left', title: { display: true, text: '万元' } },
      y1: { 
        position: 'right', 
        min: 0, max: 100,
        grid: { drawOnChartArea: false },
        title: { display: true, text: '累计占比%' }
      }
    }
  }
}
```

## 七、数据质量注意事项

⚠️ **已发现的异常数据**：

1. **负值记录**: 收入有 -300 万、回款有 -12 万（可能是冲销/调整）
2. **极端回款率**: 上汽通用五菱 470%、广汽集团 18.5%
3. **单季度局限**: 当前仅有 Q2 数据，趋势图需预留扩展

**处理建议**:
- 负值在图表中用特殊标记（灰色/斜线填充）
- 极端回款率添加注释气泡说明原因
- 趋势图当前显示单点，后续自动扩展为多季连线
