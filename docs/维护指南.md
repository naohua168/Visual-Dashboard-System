# 维护指南

> 版本：v1.0 | 更新：2026-08-25
> 面向日常维护人员：换数据、改指标、改配置、看日志、故障排查、数据锁定规则。

---

## 一、更新数据操作清单

每次拿到新一期 Excel，按以下顺序操作：

| 步骤 | 操作 | 位置 | 说明 |
|------|------|------|------|
| 1 | **替换原始文件** | `data/raw/` 对应目录 | 文件名保持不变（详见 [字段映射](字段映射.md)） |
| 2 | **更新指标表** | `data/sheets/手动维护/` 6 张表 | 列结构不变，改数值；月/季表**无销售列**（见 §2.2） |
| 3 | **修改时间范围** | `config/配置编辑器.xlsx` → 「时间配置」 | 保存即可 |
| 4 | **运行** | 双击 `启动系统.bat`（图形控制台，推荐）或 `run_all.bat` | 自动：配置同步 → 清洗 → 拆分 → 渲染 → 销售完成度 → 验证 |
| 5 | **查看** | `output/看板/看板_YYYYMMDD.html` | 浏览器打开 |

> ⚠ **运行前检查文件占用**：确保 `data/` 下 Excel 未被 Excel/WPS 打开，否则会报 `PermissionError`。
> 若日志提示文件被占用，关闭对应 Excel/WPS 后重新运行即可。

## 二、指标表维护

### 2.1 6 张指标表位置

| 目录 | 文件 | 对应页面 |
|------|------|---------|
| `年度收入总指标/` | 年度收入总指标.xlsx | 年度达成（收入） |
| `年度回款总指标/` | 年度回款总指标.xlsx | 年度达成（回款） |
| `季度收入指标/` | 季度收入指标.xlsx | 季度达成（收入） |
| `季度回款指标/` | 季度回款指标.xlsx | 季度达成（回款） |
| `月度收入指标/` | 月度收入指标.xlsx | 月度达成（收入） |
| `月度回款指标/` | 月度回款指标.xlsx | 月度达成（回款） |

### 2.2 列结构（2026-09-24 起：月度/季度表统一**不用销售列**）

**月度/季度表**：`客户 | 检测 | 信息 | 能源 | 海外`（单位：**万元**）

- **不写 `销售` 列**；**同名客户只保留一行**（写了多行也会自动累加，但约定一行）
- **拆分母公司按销售拆行**：客户列直接写 `母公司·销售`，如 `科技公司·王海龙`、`科技公司·李巍` 各一行
  - 中间分隔符**任意**：`·` `-` `－` `—` `/` `、` `:` 空格… 都能识别，系统统一归一化为标准键 `母公司·销售`
- 系统在实际数据侧也按同一键（`母公司·销售`）拆行，两行相加 = 该母公司全部，目标/实际可正确对齐

**年度表**：保留 `销售` 列，按"子公司名 + 销售"维护

- 销售达成页 / 销售完成度汇总表**只读年度表**；`(客户, 销售)` 还负责「重叠子公司」（同名挂在两个父组，当前 15 家）的父组判定
- 客户列也可写 `母公司·销售` 复合键（两种写法等价），但重叠子公司建议保留销售列

⚠ 一个 `销售` 单元格填多个销售名（如 `销售甲、销售乙`）**不支持**：会被当成**一个**销售名，销售达成页出现幽灵销售、真销售目标变小。

### 2.3 ⚠ 数据锁定规则

`data/sheets/手动维护/` 下 6 张指标表数据**已锁定**：

- **AI 不自动修改**，仅用户手动维护或明确要求时才可修改
- **修改前必须备份原文件**
- 系统只读指标表，不会覆盖用户改动

## 三、配置维护

### 3.1 时间范围

`config/配置编辑器.xlsx` → 「时间配置」sheet（推荐）或直接改 `config/清洗配置/cleaning_config.json` → `时间范围`。

> **回款双日期口径（2026-09-18 起）**：财务端回款必须「**业务日期**」与「**收款日期**」**同时**落在时间范围内才收录
> （配置 `数据源.财务端.回款.日期字段组 = ["日期","收款日期"]`）。收款日期为空的行视为不满足，不收录。
> 如需退回单日期口径，把 `日期字段组` 改成 `["日期"]` 即可。

| 配置项 | 示例值 | 影响页面 |
|--------|--------|----------|
| 年度累计 | `2026-01-01 ~ 2026-08-31` | 数据总览 / 年度达成 / 销售达成 / 年度同比 |
| 月度数据 | `2026-08-01 ~ 2026-08-31` | 月度达成 |
| 季度累计筛选 | `2026-07-01 ~ 2026-09-30` | 季度达成 |
| 年基线数据 | `年份: 2025, 月份: [1, 8]` | 年度同比（Phase 0） |

> 手动模式：改日期后重跑 `run_all.bat` 即生效。

### 3.2 展示规则

`config/配置编辑器.xlsx` → 「展示规则」sheet（**唯一编辑入口**）。

> ⚠️ 不要直接改 `config/前端渲染/展示规则.json`：它是运行时生成物，**下次运行会被 Excel 覆盖**（确需临时试跑可加 `--no-config`：`python main.py --no-config`）。

关键项：

| 配置项 | 说明 |
|--------|------|
| `客户矩阵.优先展示` | 填母公司组名或客户名，始终排前面 |
| `客户矩阵.最大行数` | `0`=全部；`>0`=截断 |
| `客户矩阵.排序` | 目标/实际金额/达成率降序；**未配置优先展示时按指标表顺序展示** |
| `数据总览.销售TopN` | 显示的最大销售人数 |

### 3.3 销售归属

`config/配置编辑器.xlsx` → 「销售归属」sheet（**唯一编辑入口**，当前 120 母公司 → 580 子公司）。

> ⚠️ 不要直接改 `config/清洗配置/客户销售归属.json`：它是运行时生成物，**下次运行会被 Excel 覆盖**。要新增/调整归属请改 Excel 的「销售归属」sheet（改完直接重跑即可自动同步）。

该 JSON 也是**销售拆行规则的事实源**：顶层 `_销售拆分.客户矩阵`（如 `["科技公司"]`）→ 矩阵按 `母公司·销售` 拆行（`科技公司 → 科技公司·王海龙 / 科技公司·李巍`）。`run_all.bat` 配置同步会保留此字段，不会被覆盖。

> ⚠ 跨分组移动子公司：必须**同时从原分组删除**（`_load_sub_to_parent` 跨分组重复时取首个出现的分组），否则归并到错误的父组。

### 3.4 KPI 指标总数（Hero 圆环）

`config/配置编辑器.xlsx` → **「KPI指标」sheet**（推荐）或直接改 `config/前端渲染/展示规则.json` 各页面的 `KPI指标` 区块。

**作用**：单独控制 KPI 卡片（Hero 圆环）上显示的收入/回款**指标总数**，**不影响表格/矩阵/部门卡里的明细指标**。

| 页面 | 值(万元) | 说明 |
|------|---------|------|
| 年度达成 / 收入 | 留空 或 数字 | 年度达成页 + **数据总览页**（跟随年度） |
| 年度达成 / 回款 | 留空 或 数字 | 同上 |
| 月度达成 / 收入、回款 | 留空 或 数字 | 月度达成页 |
| 季度达成 / 收入、回款 | 留空 或 数字 | 季度达成页 |

**规则**：
- **留空 = 不覆盖**，KPI 卡片仍按指标文件合计（现状）
- **填数字（万元）** = 覆盖显示，如 `50000` = 5 亿
- 只改 Hero 圆环总数，客户矩阵/部门卡明细指标始终按指标文件
- 数据总览页的年度 KPI 跟随「年度达成」的设置

### 3.5 字段映射（清洗列名匹配）

`config/配置编辑器.xlsx` → **「字段映射」sheet**（推荐）或直接改 `config/清洗配置/cleaning_config.json` → `数据源.*.列映射`。

**何时用它**：清洗报 `未找到匹配列，尝试过: [...]; 可用列名: [...]`（源文件改了列名），或想让某字段优先命中另一列。

| 列 | 说明 |
|----|------|
| 数据源 / 来源 / 标准字段 | 勿改（对应 `数据源.财务端.收入` 等配置路径） |
| 候选1..候选5 | 按优先级从左到右尝试；留空 = 不参与。可自行插入「候选6」等列，解析按数字顺序动态读取 |
| 当前命中(只读) | 上次清洗实际命中的列（来自 `logs/column_hits_*.txt`），**写回时被忽略** |
| 说明 | 备注；`--init-map` 会自动标注「唯一候选」「靠第 N 候选命中」等脆弱点 |

**规则**：
- 匹配是**全名精确匹配**（仅忽略首尾空白），**不是**关键词匹配 → 必须填与源文件完全一致的列名
- 每个字段至少保留 1 个候选；同一字段内候选不能重复
- **不允许删除**某来源原有的标准字段（删了会让清洗报 KeyError）→ 校验会拒绝写回
- 本 sheet 只管「列映射」；文件名/引擎/金额除数/`过客户白名单`/事业部固定等仍在 JSON 里改
- 校验失败时生成器拒绝写回并提示原因，JSON 保持原样

**排查辅助**：`logs/column_hits_YYYYMMDD.txt` 记录每次清洗的命中表（含候选次序与 ⚠️ 降级命中汇总）。

## 四、故障排查

| 问题 | 解决方案 |
|------|----------|
| 找不到 pandas / 依赖 | `pip install -r requirements.txt`（Conda 环境：`conda activate visual-dashboard-system`） |
| Excel 文件被占用（PermissionError） | 关闭 Excel/WPS 中打开的数据文件后重跑 |
| 预检失败 | 检查 `data/raw/` 下原始 Excel 是否齐全（文件名固定） |
| 改了 Excel 配置没生效 | 确认已保存；`run_all.bat` 会自动同步；若直接 `python main.py` 需先运行 `python scripts/config_excel_to_json.py` |
| 白名单匹配率低 | **仅财务端 `收入.xlsx`/`回款.xlsx` 过白名单**（广东/湖南/南方韶关、运营端、年基线不过）；检查 `data/raw/客户名单/客户名单.xlsx` 是否含该客户；匹配缓存 `data/mappings/客户名单/` |
| 想知道字段实际命中了哪一列 / 源文件改了列名 | 看 `logs/column_hits_YYYYMMDD.txt`（每次清洗追加，标出候选次序与 ⚠️ 降级命中）；报 KeyError 时看控制台/日志里的「可用列名」清单，照抄进 `cleaning_config.json` 的候选列名即可 |
| 月度/季度/年度数据为空 | 检查「时间配置」日期范围与数据实际月份匹配 |
| 矩阵出现裸"母公司"行（未拆销售） | 检查 `客户销售归属.json → _销售拆分.客户矩阵` 是否含该母公司；拆分母公司的指标行是否按 `母公司·销售` 维护（月/季表客户列直接写 `科技公司·王海龙`，分隔符任意） |
| 销售页某销售目标为空 | 年度表 `销售` 列是否与该销售名一致（如 广州计测 销售列=黎国键 → 归黎国键）；销售页只读**年度**指标表 |
| 指标表客户名写法两种混用 | 两种等价：① 客户名 + `销售` 列；② 客户列直接写 `母公司·销售`（分隔符任意）。月/季表统一用②（无销售列） |
| 看板折叠/顺序不对 | 折叠优先级（2026-09-21 口径）：**① 有「优先展示」配置 → 按优先展示折叠（名单内进主表，含非指标客户）；② 没有「优先展示」配置 → 非指标客户（该口径指标合计=0）一律折叠**。`最大行数` 只截断指标客户 |
| Hero 圆环指标总数想单独改 | 配置编辑器「KPI指标」sheet 填万元值；留空=按指标文件合计 |
| KPI 改了没生效 | 确认已保存 Excel 并重跑 run_all.bat（配置同步会自动写回 JSON） |
| 输出为空 / 看板异常 | 查看 `logs/run_YYYYMMDD_HHMMSS.log` 逐步定位 |

## 五、数据安全与备份

- `data/raw/`、`data/mappings/`、`data/sheets/`、`output/`、`logs/` 已通过 `.gitignore` 排除，**不上传 GitHub**
- 修改指标表、销售归属等关键数据前**先备份原文件**
- 交付他人时使用 `package.bat` 生成 zip（含代码+配置+目录骨架，不含敏感数据）
