# 数据文件方案

> 新系统采用 **方案A（拆分模式）**：旧系统 `data.xlsx` 的 10 个 Sheet 拆分为独立 CSV/JSON 文件  
> 大表（>100 行）→ CSV，小表（≤100 行）→ JSON  
> 十步流水线处理，`main.py` 统一调度，每步独立进程可中断恢复

### 旧系统问题

| 问题 | 说明 |
|------|------|
| 原始数据、规则、脚本、输出混在一个目录 | 难管理 |
| 客户名单放两份（财务端+运营端各一份） | 冗余 |
| data.xlsx 10个Sheet混合（自动生成+手工维护） | 容易误覆盖手工数据 |
| 规则配置和代码放一起 | 改规则需改代码 |
| 映射字典硬编码在Python里 | 维护困难 |
| 列索引硬编码 | 源文件列变化→提取错数据 |
| 脚本扁平排列在 damo/ | 无隔离，改一步可能影响全局 |
| 无原始数据备份 | 出错无法回溯 |
| 无预览模式 | 改一步必须全量运行 |

### 新系统改进

| 改进 | 旧系统 | 新系统 |
|------|--------|--------|
| 数据存储 | 1个 data.xlsx 10个Sheet混放 | data/processed/ 拆分为 7 CSV + 3 JSON 独立文件 |
| 原始备份 | 无 | data/raw/ 每次运行自动时间戳备份 |
| 数据快照 | output/data(日期).xlsx 单文件 | output/data/{时间戳}/ 全量文件副本 + summary.json |
| 输出分离 | HTML + xlsx 混放 output/ | output/数据大屏/ (HTML) + output/data/ (快照) 分离 |
| 脚本结构 | damo/ 扁平排列 12 个 .py | scripts/step{1-10}/ 逐层隔离，每步独立目录 |
| 调度方式 | main.py 同步调用函数 | main.py subprocess 独立进程（可中断恢复） |
| 预览模式 | 无 | `--dry-run` 支持 |
| 步骤选择 | 全量运行 | `--step=N` / `--from=N --to=M` 灵活选择 |
| 运行日志 | print | print + summary.json 元数据 |
| 小表格式 | xlsx 全部统一 | 小表(≤100行)用 JSON，大表用 CSV，兼顾可读与效率 |

### 10个数据文件分类

#### 自动生成（4个）— 清洗引擎写入

| 文件 | 来源 | 格式 | 说明 |
|------|------|------|------|
| `收入.csv` | Step1 财务端 + Step2 运营端合并 | CSV | 四源合并，清洗后标准表（6列） |
| `回款.csv` | Step1 财务端 + Step2 运营端合并 | CSV | 四源合并，清洗后标准表（6列） |
| `销售收入.csv` | Step7 从 `收入.csv` 按销售规则拆分 | CSV | 客户→销售维度转换（7列） |
| `销售回款.csv` | Step7 从 `回款.csv` 按销售规则拆分 | CSV | 客户→销售维度转换（7列） |

#### 手工维护（6个）— 从 data.xlsx 拆分，系统只读

| 文件 | 用途 | 格式 | 维护频率 |
|------|------|------|----------|
| `总指标.json` | 年度目标值，计算达成率的分母 | JSON | 年初定一次 |
| `月度收入指标.json` | 月度收入目标 | JSON | 每月初更新 |
| `月度回款指标.json` | 月度回款目标 | JSON | 每月初更新 |
| `2024年收入.csv` | 去年同期收入（同比基线） | CSV | 年初导入一次 |
| `2024年回款.csv` | 去年同期回款（同比基线） | CSV | 年初导入一次 |
| `商机.csv` | 外部CRM系统导出 | CSV | 按需导入 |

## 四、运行方式

```bash
# 一键全流程运行（Step 0-10）
python main.py

# 只运行拆分步骤
python main.py --step=0

# 从拆分到月度达成（Step 0-6）
python main.py --from=0 --to=6

# 预览模式（不写文件，仅验证流程）
python main.py --dry-run

# 单独运行某个步骤
python main.py --step=3     # 只执行填入总指标
```

## 七、技术栈

| 层次 | 技术 | 用途 |
|------|------|------|
| 数据读取 | pandas, openpyxl, xlrd | 读取 .xlsx/.xls 原始数据 |
| 数据处理 | pandas (groupby/merge/apply) | 数据清洗、分组聚合、拆分配置 |
| 配置管理 | JSON (config/config.json) | 时间/路径/规则配置 |
| HTML渲染 | BeautifulSoup4 | 精准注入数据到模板DOM节点 |
| 调度管理 | main.py (+ subprocess) | 串联十步流水线，错误处理 |
| 数据输出 | shutil/csv/json | 文件复制、CSV导出、快照归档 |
