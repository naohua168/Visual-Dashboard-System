## 二、十步流水线

```
Step 0: 年基线提取
    python -m engine.yearly_baseline.run
    → data/sheets/年收入/年收入.xlsx
    → data/sheets/年回款/年回款.xlsx

Step 1: 财务端收入清洗
    financial.py → 列提取 → 日期筛 → 内交排除 → 部门映射 → 白名单
    → 财务端收入DataFrame（当月）

Step 2: 财务端回款清洗
    financial.py → 列提取 → 日期筛 → 内交排除 → 部门映射 → 白名单
    → 财务端回款DataFrame（当月）

Step 3: 广东公司清洗（收入+回款）
    financial.py → 万元转元 → 固定事业部="检测" → 白名单(可选)
    → 广东收入/回款DataFrame

Step 4: 湖南公司清洗（收入+回款）
    financial.py → 万元转元 → 固定事业部="信息" → 白名单
    → 湖南收入/回款DataFrame

Step 5: 运营端收入清洗
    operations.py → 内交过滤 → 部门映射 → 日期保留原文 → 广东/深圳识别
    → 运营端收入DataFrame（1-4月+5月）

Step 6: 运营端回款清洗
    operations.py → 内交过滤 → 部门映射 → 日期保留原文 → 广东/深圳识别
    → 运营端回款DataFrame（1-4月+5月）

Step 7: 合并输出（三路）
    income_payment/run.py
    → 月收入/月回款 ← 仅财务端
    → 当年累计收入/回款 ← 财务端+运营端
    → 收入/回款 ← 同上（兼容）

Step 8: 销售拆分
    sales/run.py → 4层匹配 → 金额拆分 → 总额校验
    → 销售收入/销售回款

Step 9: 渲染看板
    processors/run.py → 加载7表 → 5页HTML → output/
```

## 三、运行方式

### 3.1 顶层调度器（推荐）

```bash
python main.py                          # 全流程：yearly → clean → split → render
python main.py --step=yearly            # 只提取年基线
python main.py --step=clean             # 只清洗（Phase 1+2）
python main.py --step=split             # 只拆分（Phase 3）
python main.py --step=render            # 只渲染（Phase 4）
python main.py --from=clean --to=render # 区间执行
python main.py --dry-run                # 预检模式
python main.py --list                   # 列出所有步骤
```

### 3.2 直接调用（调试用）

```bash
python -m engine.yearly_baseline.run --source=2025年收入回款.xlsx
python -m engine.income_payment.run --type=收入
python -m engine.income_payment.run --type=回款
python -m engine.sales.run
python -m processors.run --output=自定义.html
```

### 3.3 运行测试

```bash
python -m pytest tests/ -v              # 全部86用例
python -m pytest tests/test_render.py   # 渲染测试
python -m pytest tests/ -k "splitter"   # 按关键字
```

## 四、标准表结构

### 4.1 收入/回款（6列）

| 列名 | 类型 | 说明 |
|---|---|---|
| 事业部 | str | 检测/信息/能源/海外（已简称） |
| 金额 | float | 统一为元 |
| 客户 | str | 白名单匹配后的标准客户名 |
| 日期 | str | 财务端=原始日期，运营端="1-4月"/"5月" |
| 是否为广东公司 | str | "是" 或 空 |
| 是否为深圳公司 | str | "是" 或 空 |

### 4.2 销售收入/销售回款（7列）

6列 + `销售` 列（销售人员姓名）。

### 4.3 总指标（6列）

| 列名 | 类型 | 说明 |
|---|---|---|
| 客户 | str | 客户名称（42行） |
| 销售 | str | 销售人员 |
| 检测 | float | 检测事业部年度目标（万元） |
| 信息 | float | 信息事业部年度目标（万元） |
| 能源 | float | 能源事业部年度目标（万元） |
| 海外 | float | 海外事业部年度目标（万元） |

### 4.4 月度指标（5列）

| 列名 | 类型 | 说明 |
|---|---|---|
| 客户 | str | 客户名称（37行） |
| 检测 | float | 检测事业部月度目标 |
| 信息 | float | 信息事业部月度目标 |
| 能源 | float | 能源事业部月度目标 |
| 海外 | float | 海外事业部月度目标 |

## 五、数据安全

以下目录/文件已通过 `.gitignore` 排除，**绝不**上传 GitHub：

| 排除内容 | 原因 |
|---|---|
| `data/raw/` | 真实业务数据（客户名单/回款/收入） |
| `data/mappings/` | 业务规则配置 |
| `data/sheets/` | 清洗输出 |
| `.codebuddy/` | IDE 本地元数据 |
| `__pycache__/` | Python 缓存 |
| `2025年收入回款.xlsx` | 年基线源文件 |

## 六、数据依赖关系

```
原始文件                        清洗输出                    渲染输入
────────────────────────────────────────────────────────────────────
收入.xlsx          ──→ 月收入.xlsx ──┐
回款.xlsx          ─→ 月回款.xlsx ──┤
广东公司.xlsx      ─→              ├── 收入.xlsx ──→ 看板.html
湖南公司.xlsx      ─→              │   回款.xlsx
运营端收入.xls     ─→ 当年累计收入 ─┘   销售收入.xlsx
运营端回款.xls     ─→ 当年累计回款 ──→  销售回款.xlsx
                                    ┌── 总指标.xlsx
客户名单.xlsx ──→ 白名单过滤 ──────┼── 月度收入指标.xlsx
                                    ├── 月度回款指标.xlsx
2025年收入回款.xlsx ──→ 年收入.xlsx └── 年回款.xlsx
```
