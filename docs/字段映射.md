# 字段映射参考

> 版本：v6.1 | 更新：2026-08-25
> 作用：每个数据源的标准字段 → Excel 候选列名（按优先级匹配）→ 当前实际命中的列。
> 系统按候选列名**顺序**尝试匹配，只要 Excel 列名含关键词即可识别，字段名变化时无需改代码。

---

## 一、财务端（`data/raw/财务端数据/`）

### 1.1 收入.xlsx（56+ 列，Sheet: Sheet1→列表数据，金额单位：元）

| 标准字段 | 候选列名（按序尝试） | 当前命中 |
|----------|----------------------|---------|
| 日期 | `创建时间` / `创建日期` / `审核日期` | 创建时间 |
| 客户 | `客户.名称` / `客户名称` / `客户.姓名` | 客户.名称 |
| **金额** | **`不含税金额`** / `含税金额` / `金额` / `含税金额总计` | 不含税金额 |
| 部门 | **`成本中心.名称`** / `成本中心` | 成本中心.名称 |
| 法人主体 | `公司` | 公司 |

### 1.2 回款.xlsx（60+ 列，Sheet: Sheet1→列表数据，金额单位：元）

| 标准字段 | 候选列名（按序尝试） | 当前命中 |
|----------|----------------------|---------|
| 日期 | `业务日期` / `收款日期` / `创建时间` | 业务日期 |
| 客户 | `付款人(客户).名称` / `付款人名称` / `付款人(客户).姓名` / `客户.名称` | 付款人名称 |
| **金额** | **`应收金额`** / `实收` / `收款金额` / `金额` | 应收金额 |

> ⚠ **口径**：收入金额取 `不含税金额`，回款金额取 `应收金额`——这是看板数据与财务口径一致的关键。
> ⚠ **客户区域筛选已移除**（2026-08-24）：不再按 `客户区域=三区` 过滤，财务端保留全部区域客户。

### 1.3 广东公司.xlsx（收入/回款双 Sheet，金额单位：万元）

| 标准字段 | 候选列名 | 说明 |
|----------|---------|------|

### 1.4 湖南公司.xlsx（收入/回款双 Sheet，金额单位：万元）

### 1.5 南方韶关.xlsx（收入/回款双 Sheet，金额单位：万元，**无表头**）

按**列位置**提取（非列名）：

| 列位置 | 含义 |
|--------|------|
| 第 0 列 | 客户 |
| 第 1 列 | 日期 |
| 第 2 列 | 金额（万元，×10000 → 元） |

特殊处理：部门**固定="检测"**、法人主体**固定**="南方（韶关）智能网联新能源汽车试验检测中心有限公司"、需过客户白名单。回款 Sheet 可能为空（当前无数据时返回空）。

## 五、手工指标表（`data/sheets/手动维护/`，6 张）

统一列结构（单位：**万元**）：

| 列名 | 类型 | 说明 | 示例 |
|------|------|------|------|
| 客户 | 文本 | 客户全称 | 比亚迪汽车工业有限公司 |
| 销售 | 文本 | 负责销售名 | 黄灿 |
| **检测** | 数字 | 检测事业部指标（万元） | 5000 |
| **信息** | 数字 | 信息智能事业部指标（万元） | 500 |

## 六.5 KPI 指标覆盖（展示规则.json → `KPI指标` 区块）

| 字段 | 含义 | 单位 |
|------|------|------|
| `KPI指标.收入` | 覆盖 Hero 圆环显示的收入指标总数 | 万元 |
| `KPI指标.回款` | 覆盖 Hero 圆环显示的回款指标总数 | 万元 |

- 配置入口：`config/配置编辑器.xlsx` → 「KPI指标」sheet
- 适用于 `年度达成` / `月度达成` / `季度达成` 三个页面（数据总览页的年度 KPI 跟随「年度达成」）
- 留空/缺省 = 不覆盖，按指标文件合计；填数字（万元） = 覆盖显示
- **只影响 KPI 卡片（Hero 圆环）总数，不影响客户矩阵/部门卡明细指标**

## 七、标准输出格式（清洗后）

### 收入/回款（6 列标准表）

| 列名 | 类型 | 说明 |
|------|------|------|
| 事业部 | str | 检测/信息/能源/海外（已简称） |
| 金额 | float | 统一为**元** |
| 客户 | str | 白名单匹配后的标准客户名 |
| 法人主体 | str | 财务端来源保留；运营端取法人主体列 |
| 日期 | str/Timestamp | 清洗后统一 |
| 是否为广东公司 | str | "是" 或 空 |

### 销售收入/销售回款（7 列）

6 列 + `销售` 列（一行按比例可拆为多行）。
