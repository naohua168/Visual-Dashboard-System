# 字段映射参考

> 版本：v6.3 | 更新：2026-09-17
> 作用：每个数据源的标准字段 → Excel 候选列名（按优先级匹配）→ 当前实际命中的列（含候选次序）。
> **改列名不用改代码/JSON**：候选列名可在 `config/配置编辑器.xlsx` → **「字段映射」sheet** 直接增删，保存后 `run_all.bat` 自动写回 `cleaning_config.json`（详见 [维护指南](维护指南.md) 3.5）。
> 系统按候选列名**顺序**做**全名精确匹配**（仅去首尾空白）——**不是**关键词/模糊匹配，候选列名必须与源文件列名完全一致。
> 命中表在每次清洗时自动落盘到 `logs/column_hits_YYYYMMDD.txt`（含候选次序与 ⚠️ 降级标记），可直接据此定位脆弱字段。
> 当前降级命中共 **9 处**（2026-09-17 实测）：财务端收入 部门、财务端回款 法人主体、运营端收入 日期/金额/内部交易/核算单位、运营端回款 金额/内部交易/核算单位。

### 1.2 回款.xlsx（60+ 列，Sheet: Sheet1→列表数据，金额单位：元）

| 标准字段 | 候选列名（按序尝试） | 当前命中 |
|----------|----------------------|---------|
| 日期 | `业务日期` / `收款日期` / `创建时间` | 业务日期 |
| 客户 | `付款人(客户).名称` / `付款人名称` / `付款人(客户).姓名` / `客户.名称` | 付款人(客户).名称（1/4） |
| **金额** | **`应收金额`** / `实收` / `收款金额` / `金额` | 应收金额（1/4） |
| 部门 | **`成本中心.名称`** / `成本中心` | 成本中心.名称（1/2） |
| 法人主体 | `公司` / `收款公司` | ⚠️ 收款公司（**2/2，降级**） |
| **收款日期** | **`收款日期`** | 收款日期（1/1）· **可选字段** |

> **回款双日期口径（2026-09-18 新增）**：财务端回款需 **业务日期 与 收款日期 同时落在时间范围内**才收录。
> - 配置：`数据源.财务端.回款.日期字段组 = ["日期","收款日期"]`；`收款日期` 同时列入 `可选字段`
> - `日期字段组` 内所有字段会依次做范围筛选（AND 语义）；除首个字段外的字段缺失时**自动降级为单日期筛选并打 WARN**，不中断清洗
> - 收款日期为空值的行视为**不满足**（不在窗口内 → 不收录）
> - 实测影响（9 月窗口）：632 行 → 541 行（排除 91 行）；最终财务端主表 **20 行 → 18 行（−291,800 元）**

> **命中次序说明**（2026-09-17 实测校正）：括号内为「第几个候选命中 / 候选总数」。
> **⚠️ 降级命中** = 第一候选在源文件中**根本不存在**，靠后备候选兜住——余量很薄，源表改名前需留意。
> 命中表在每次清洗时自动落盘到 `logs/column_hits_YYYYMMDD.txt`（按天追加，含降级标记与汇总行）。

> ⚠ **口径**：收入金额取 `不含税金额`，回款金额取 `应收金额`——这是看板数据与财务口径一致的关键。
> ⚠ **客户区域筛选已移除**（2026-08-24）：不再按 `客户区域=三区` 过滤，财务端保留全部区域客户。

> ⚠ **白名单适用范围（2026-09-17 明确）**：客户白名单**只对财务端 `收入.xlsx` / `回款.xlsx` 两张主表生效**（配置 `过客户白名单=true`）。

> **「南方韶关」母公司行（2026-09-20，年/月/季度达成页）**
> 规则（**按行判定，不需要维护客户名单**）：
> - `法人主体 = 南方（韶关）智能网联新能源汽车试验检测中心有限公司` **且** 该行在「该口径（收入/回款）+ 该部门」下**查不到销售归属** → 客户名改为母公司 **`南方韶关`** 聚合展示（点开弹窗/抽屉可见各客户明细）；
> - 有销售归属的韶关行 → 保持原客户行（走销售）；
> - 法人主体 ≠ 南方（韶关）→ 不归拢。
>
> 实现：`processors/page_data_utils.filter_sg_by_legal()`（在 `_consolidate_customers(df, "收入"/"回款")` 内调用），仅年度/月度/季度三个页面传入 metric；总览/同比不做该归拢。

> **2026-09-17 变更**：源文件已加表头（`客户`/`日期`/`金额`），该来源由「按列位置提取」改为「按列名提取」。
> 如需退回无表头格式，在 `cleaning_config.json` 该来源下加 `"无表头": true` + `"列位置": {"客户":0,"日期":1,"金额":2}` 即可（代码保留双格式兼容）。

## 七、标准输出格式（清洗后）

### 收入/回款（5 列标准表）

| 列名 | 类型 | 说明 |
|------|------|------|
| 事业部 | str | 检测/信息/能源/海外（已简称） |
| 金额 | float | 统一为**元** |
| 客户 | str | 主表：白名单匹配后的标准客户名；广东/湖南/南方韶关/运营端/年基线：规范化清洗后的原始名 |
| 法人主体 | str | 财务端取自 `公司`/`收款公司` 等列；广东/湖南/南方韶关为固定值；运营端取 `法人主体` 列 |
| 日期 | str/Timestamp | 清洗后统一 |

### 销售收入/销售回款（7 列）

6 列 + `销售` 列（一行按比例可拆为多行）。
