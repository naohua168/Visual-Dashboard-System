## 三、4-Phase 清洗流水线

### 3.1 Phase 0: 年基线清洗

**入口**：`engine/yearly_baseline/cleaner.py::run_clean(mapper)`

**查找**：通配符 `glob("*.xlsx")` 在 `往年收入数据/` 和 `往年回款数据/` 中匹配第一个文件。

**清洗步骤**（`_clean_single`）：
1. `pd.read_excel(file_path)` 读取
2. 客户列重命名：`客户名称/客户名/客户` → `客户`
3. 金额列重命名：`收入金额/到款金额/收入/到款/金额` → `金额`
4. 事业部映射：`map_income_dept` + 硬编码 `DEPT_MAP` 兜底
5. `pd.to_numeric(errors="coerce")` 金额转数值
6. 日期列动态发现（含"时间/日期/确认"关键词）→ `_parse_yearly_date`（取末月）
7. 补齐 `是否为广东公司=""`、`是否为深圳公司=""`
8. 标准化输出 → 6列

**输出**：`data/sheets/系统数据清理/往年收入/往年收入.xlsx` + `往年回款/往年回款.xlsx`

### 3.2 Phase 1: 财务端清洗

**入口**：`engine/income_payment/financial.py::clean_financial(config, mapper, matcher, file_type, time_range)`

**三路来源**：
| 函数 | 来源 | 特殊处理 |
|------|------|---------|
| `clean_financial_main` | 收入.xlsx/回款.xlsx | `filter_by_date` → `is_excluded`(3家) → `map_payment_dept`(50+条) → 白名单 |
| `clean_guangdong` | 广东公司.xlsx | 金额×10000 → 事业部="检测" → `是否为广东公司="是"` |
| `clean_hunan` | 湖南公司.xlsx | 金额×10000 → 事业部="信息" |

**输出**：`pd.concat([主表, 广东, 湖南])` = 财务端当月完整数据（6列）

### 3.3 Phase 2: 运营端清洗

**入口**：`engine/income_payment/operations.py::clean_operations(config, mapper, matcher, file_type, fixed_date)`

**清洗步骤**：
1. `pd.read_excel(file_path, sheet_name, "xlrd")` 读取
2. `extract_columns()` 列名提取
3. 内部交易过滤：剔除 `是否属于内部交易 == "是"`
4. `map_income_dept()` 事业部映射（收入版4条）
5. `_parse_ops_date` 日期解析（取末月，fallback fixed_date）
6. 广东/深圳识别：`法人主体.str.contains("广东|深圳")`
7. 非广东/深圳 → 白名单过滤；广东/深圳 → **不经白名单**
8. `standardize_output()` → 6列

### 3.4 三路合并输出

**入口**：`engine/income_payment/run.py::run_clean(file_type, config)`

```python
df_monthly       = df_financial                              # 月数据（仅财务端）
df_yearly        = concat([df_financial, df_ops])            # 当年累计（全量）
df_quarterly     = concat([df_financial, _filter_ops_by_quarter(df_ops)])  # 季度累计
```

**季度筛选**：`_filter_ops_by_quarter()` → 取系统上月 → 定 Q_start/Q_end → 筛选运营端月份

| 输出 | 数据组成 | 用途 |
|------|---------|------|
| 月收入/月回款 | 仅财务端当月 | 月度达成 |
| 当年累计收入/回款 | 财务端+运营端全量 | 年度达成+销售拆分 |
| 季度累计收入/回款 | 财务端+运营端当季 | 季度分析 |

### 3.5 Phase 3: 销售拆分

**入口**：`engine/sales/run.py::run_split(file_type, config)`

**4层匹配**（`SalesSplitter.split()`）：

| 层级 | 匹配方式 | 数据源 |
|------|---------|--------|
| 广东公司规则 | 客户名精确 | `rules_data["广东公司规则"]` |
| 深圳公司规则 | 客户名精确 | `rules_data["深圳公司规则"]` |
| 其他规则(~140) | 客户名精确 | `rules_data["其他规则"]` |
| 默认规则(~340) | 统称继承+兜底 | `rules_data["默认规则"]` |
| 待确认 | 未匹配 | — |

**统称继承**：加载 `客户统称名单.json` → `subsidiary_to_parent` dict → 子公司在默认规则未匹配时继承母公司规则

**规则格式兼容**（4种变体）：
- A: `{"事业部": {"检测": {"销售": [...], "比例": {...}}}}` — 标准事业部级
- B: `{"销售": [...], "比例": {...}}` — 无事业部（全适用）
- C: `{"事业部": {}}` — 空事业部（全适用）
- D: `{"事业部": {"默认": {...}}}` — 默认部门兜底

**金额拆分与校验**：
- 金额 × 比例（不四舍五入，保留完整精度）
- `abs(拆分前 - 拆分后) < 1e-6` 视为通过
- 无比例配置时按销售人数均分

**输出**：原6列 + `销售` 列 = 7列，一行可拆为多行

## 六、配置驱动

全部参数在 `config/清洗配置/cleaning_config.json` 中定义，7段配置：

| 段 | 作用 | 示例 |
|---|---|---|
| `数据源` | 原始Excel路径+引擎+列映射 | `收入.xlsx`→Sheet1→openpyxl |
| `映射文件` | 2个清洗映射JSON路径 | `部门事业部映射.json`（Phase 1+2 用） |
| `时间范围` | 数据筛选区间 | 支持 `dynamic` 模式：`_strategy: last_full_month` 取上月，`last_full_quarter` 取上季度 |
| `客户匹配` | 白名单策略 | 去空格匹配 + 广东公司不经白名单 |
| `输出` | 清洗后路径+标准列 | `data/sheets/系统数据清理/月收入/` |
| `手工指标表` | 目标数据路径 | 总指标 / 月度指标 |
| `渲染输出` | 看板生成参数 | 6页HTML + 11Sheet Excel |

### 6.1 动态时间模式（自动按月/季切换）

`cleaning_config.json` 中时间范围支持两种模式：

```json
"时间范围": {
  "月度数据": {
    "_mode": "dynamic",
    "_strategy": "last_full_month",
    "start_date": "2026-06-01",   // 静态 fallback
    "end_date": "2026-06-30 23:59:59"
  },
  "季度累计筛选": {
    "_mode": "dynamic",
    "_strategy": "last_full_quarter",
    "start_date": "2026-04-01",
    "end_date": "2026-06-30 23:59:59"
  }
}
```

- `_mode: dynamic` + `_strategy: last_full_month` → 取**上一个完整月**（不包含当前未结束月）
- `_mode: dynamic` + `_strategy: last_full_quarter` → 取**上一个完整季度**（不包含当前未结束季）
- 不带 `_mode` 字段 → 静态模式，使用 `start_date` / `end_date` 硬编码值

**测试覆盖**：11 个 test_config 用例覆盖跨年/闰年/季度边界场景。
