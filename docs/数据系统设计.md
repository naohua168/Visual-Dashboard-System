## 三、4-Phase 清洗流水线

```
Phase 0: 年基线清洗  往年收入/回款 → 往年收入/回款（6列标准表）
Phase 1+2: 收入/回款 财务端(当月) + 运营端(当年累计) → 三路输出（月/季度累计/当年累计）
Phase 3: 销售拆分    4层匹配 + 总额校验 → 销售收入/回款（7列，含销售列）
Phase 4: 渲染看板    6页HTML + Excel总表 → output/
```

### 3.1 Phase 0: 年基线清洗

**入口**：`engine/yearly_baseline/cleaner.py::run_clean()`

**查找**：从 `cleaning_config.json → 年基线数据` 读取精确文件路径（不再 glob 通配）。

**清洗步骤**：
1. `pd.read_excel(file_path)` 读取
2. 客户列重命名：`客户名称/客户名/客户` → `客户`
3. 金额列重命名：`收入金额/到款金额/收入/到款/金额` → `金额`
4. 事业部映射：`map_income_dept`（全称→简称）
5. `pd.to_numeric(errors="coerce")` 金额转数值
6. 日期列动态发现 → `_parse_yearly_date`（统一赋 `YEAR_LABEL-01-01`，无月份粒度）
7. 补齐 `是否为广东公司=""`、`是否为深圳公司=""`
8. 标准化输出 → 6列

**输出**：`data/sheets/系统数据清理/往年收入/` + `往年回款/`

> **年基线月份粒度检测**：`has_yearly_baseline` 检测 `nunique()<=1` → 返回 False → 页面同比自动降级不显示。

### 3.2 Phase 1: 财务端清洗

**入口**：`engine/income_payment/financial.py::clean_financial()`

**三路来源**：

| 函数 | 来源 | 特殊处理 |
|------|------|---------|
| `clean_financial_main` | 收入.xlsx / 回款.xlsx | `filter_by_date` → 内部交易排除 → 部门映射 → **白名单过滤** |
| `clean_guangdong` | 广东公司.xlsx | 金额×10000 → 部门="检测" → `是否为广东公司="是"` |
| `clean_hunan` | 湖南公司.xlsx | 金额×10000 → 部门="信息" |

**输出**：`pd.concat([主表, 广东, 湖南])` = 财务端当月完整数据（6列标准表）

### 3.3 Phase 2: 运营端清洗

**入口**：`engine/income_payment/operations.py::clean_operations()`

**清洗步骤**：
1. `pd.read_excel(file_path, sheet_name, engine="xlrd")` 读取
2. `extract_columns()` 列名提取
3. 内部交易过滤：剔除 `是否属于内部交易 == "是"`
4. `map_income_dept()` 事业部映射
5. `_parse_ops_date` 日期解析（取末月）
6. 广东/深圳识别：`法人主体.str.contains("广东|深圳")`
7. **运营端全量通过白名单**（不筛选）
8. `standardize_output()` → 6列

### 3.4 三路合并输出

**入口**：`engine/income_payment/run.py::run_clean()`

```python
df_monthly   = df_financial                                   # 月数据（仅财务端当月）
df_yearly    = concat([df_financial, df_ops])                 # 当年累计（全量）
df_quarterly = concat([df_financial, _filter_ops_by_quarter(df_ops)])  # 季度累计
```

**季度筛选**：`_filter_ops_by_quarter()` → 按时间范围配置筛选运营端月份

| 输出 | 数据组成 | 用途 |
|------|---------|------|
| 月收入/月回款 | 仅财务端当月 | 月度达成页 |
| 当年累计收入/回款 | 财务端+运营端全量 | 年度达成+销售拆分 |
| 季度累计收入/回款 | 财务端+运营端当季 | 季度分析页 |

### 3.5 Phase 3: 销售拆分

**入口**：`engine/sales/run.py::run_split()`

**数据源**：`config/清洗配置/客户销售归属.json`（96 母公司 → 548 子公司 → 收入/回款 → 4部门 → 销售 → 比例）

**拆分逻辑**：
1. 客户名 → 匹配归属：查找 `母公司.子公司`，子公司名=客户名 或 客户名命中母公司归拢名
2. 命中 → 取该子公司对应指标（收入/回款）×部门 的销售分配
3. 比例默认 1.0（全额）；`0<比例≤1` 支持拆分（如 比亚迪 多销售按比例拆）
4. 未命中 → 标记**"待确认"**（不丢弃，用于待确认客户弹窗）

**比亚迪法人主体拆分**（`_apply_byd_sales_override`）：
- 扫描原始数据找出重名子公司 → 按法人主体分配：广东检测中心→黄浩浩，非广东→周涵林

**金额拆分与校验**：
- 金额 × 比例（保留完整精度，不四舍五入）
- `abs(拆分前 - 拆分后) < 1e-6` 视为通过

**输出**：原6列 + `销售` 列 = 7列，一行可拆为多行

### 3.6 Phase 4: 渲染看板

**入口**：`processors/run.py::run_render()`

| 页面 | 核心组件 |
|------|---------|
| 数据总览 | Hero 双环 + 事业部矩阵 + 销售 Top N |
| 年度达成 | Hero + 部门卡 + 客户达成矩阵(cell-bg) + 子公司抽屉弹窗 |
| 月度达成 | Hero + 部门卡 + 客户达成矩阵 + 子公司抽屉弹窗 |
| 季度达成 | Hero + 部门卡 + 客户达成矩阵 + 子公司抽屉弹窗 |
| 销售达成 | 卡片1:销售进度条 / 卡片2:销售×事业部矩阵 / 卡片3:销售×客户矩阵 + 抽屉弹窗 |
| 年度同比 | 事业部同比表 + 客户同比矩阵（无年基线粒度时降级） |

## 五、运行方式

```bash
# 一键运行（Windows，推荐）
run_all.bat

# 全流程
python main.py

# 分步
python main.py --step=yearly    # 仅年基线清洗
python main.py --step=clean     # 仅收入/回款清洗
python main.py --step=split     # 仅销售拆分
python main.py --step=render    # 仅渲染看板
python main.py --type=收入       # 仅收入链路
python main.py --from=clean --to=render   # 区间执行
python main.py --dry-run        # 预检（检查 raw/mappings/config）
python main.py --list           # 列出所有步骤
```

## 六、配置驱动

### 6.1 `cleaning_config.json`（清洗核心配置，7 段）

| 段 | 作用 |
|----|------|
| `数据源` | 财务端/运营端 Excel 路径 + 引擎 + 列映射 + 金额除数 |
| `年基线数据` | 往年收入/回款精确文件路径 |
| `客户名单` | 白名单 Excel 路径 |
| `映射文件` | 部门映射 + 客户名单 JSON 路径 |
| `时间范围` | 数据筛选区间（静态/动态模式） |
| `输出` | 清洗后 10 个输出目录 + 标准列 + 金额单位 |
| `手工指标表` | 6 张目标表路径 |

**时间范围动态模式**：
```json
"月度数据": {
  "_mode": "dynamic",
  "_strategy": "last_full_month",
  "start_date": "2026-07-01",   // 静态 fallback
  "end_date": "2026-07-31 23:59:59"
}
```
- `_mode: dynamic` + `last_full_month` → 取上一个完整月
- `_mode: dynamic` + `last_full_quarter` → 取上一个完整季度
- 无 `_mode` → 静态模式，用 start_date/end_date

### 6.2 配置编辑器 `config/配置编辑器.xlsx`（编辑层）

| Sheet | 内容 | 规模 |
|-------|------|------|
| 时间配置 | 年度/月度/季度/年基线 时间范围 | 4 行 |
| 展示规则 | 6 页面的显示/最大行数/排序/优先展示/客户筛选 | ~50 行 |
| 销售归属 | 母公司→子公司→指标→部门→销售→比例 | ~2340 行 |
| 说明 | 使用指南 | — |

**同步机制**：Excel 是"编辑层"，JSON 是"事实源"。`run_all.bat` 启动时自动运行 `scripts/config_excel_to_json.py` 同步；`python main.py` 不读 Excel。

## 七、映射规则

### 7.1 部门事业部映射（`data/mappings/部门事业部映射/`）

| 来源全称 | 简称 | 适用于 |
|----------|------|--------|
| 检测工程事业部 | 检测 | 收入+回款 |
| 信息智能事业部 | 信息 | 收入+回款 |
| 能源动力事业部 | 能源 | 收入+回款 |
| 海外事业部 | 海外 | 收入+回款 |

### 7.2 客户归拢策略

- **1:1 关系**（子公司名=母公司名）：不聚合，跳过映射
- **3+ 子公司** 或 **客户名=母公司名且出现在数据中**：聚合到母公司名
- 归拢后子公司名不在列表中 → 弹窗数据从 `subs_with_data`（原始数据提取）读取

### 7.3 内部交易排除

- 财务端：硬编码排除 3 家（广东汽车检测中心 / 中汽院深圳 / 中汽院湖南）
- 运营端：按 `是否属于内部交易` 列值过滤
