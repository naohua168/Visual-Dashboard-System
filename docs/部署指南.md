# 部署指南

## 环境要求

- **Python 3.12+**（推荐使用 Conda）
- 操作系统：Windows / macOS / Linux

## 安装步骤

### 1. 解压文件

将 `Visual-Dashboard-System_vYYYYMMDD.zip` 解压到任意目录，目录名不含中文。

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 准备数据

将以下文件放入对应目录：

```
data/raw/
├── 财务端数据/
│   ├── 收入.xlsx        # 财务端收入数据
│   ├── 回款.xlsx        # 财务端回款数据
│   ├── 广东公司.xlsx    # 广东子公司数据（可选）
│   └── 湖南公司.xlsx    # 湖南子公司数据（可选）
├── 运营端数据/
│   ├── 收入.xls         # 运营端收入数据
│   └── 回款.xls         # 运营端回款数据
├── 往年收入数据/
│   └── 往年年收入.xlsx  # 同比基线
├── 往年回款数据/
│   └── 往年年回款.xlsx  # 同比基线
└── 客户名单/
    └── 客户名单.xlsx    # 白名单（提供此文件即可，JSON 自动生成）

data/mappings/
├── 部门事业部映射/
│   └── 部门事业部映射.json
└── 客户名单/
    └── 客户名单.json    # ← 系统自动从 Excel 生成，无需手动创建

data/sheets/手动维护/
├── 年度收入总指标/
├── 年度回款总指标/
├── 季度收入指标/
├── 季度回款指标/
├── 月度收入指标/
└── 月度回款指标/
```

### 4. 配置

编辑 `config/清洗配置/cleaning_config.json`：

- **数据源** → 确认文件名与Sheet名匹配
- **时间范围** → 修改 `start_date` / `end_date` 到目标时间段
- **手工指标表** → 确认指标表路径

编辑 `config/前端渲染/展示规则.json`：

- 控制各页面的客户筛选、排序、最大行数
- 配置优先展示的客户列表

## 运行

### Windows 用户 — 双击运行

直接双击 `run_all.bat`

### 命令行运行

```bash
# 全流程（推荐）
python main.py

# 预检（检查配置和数据是否齐全）
python main.py --dry-run

# 分步执行
python main.py --step=yearly    # 仅年基线清洗
python main.py --step=clean     # 仅收入/回款清洗
python main.py --step=split     # 仅销售拆分
python main.py --step=render    # 仅渲染看板

# 仅处理某类数据
python main.py --type=收入
python main.py --type=回款

# 失败重试
python main.py --from=clean     # 从清洗步骤开始
```

## 输出

| 文件 | 路径 | 说明 |
|------|------|------|
| 可视化看板 | `output/看板/看板_YYYYMMDD.html` | 6页交互式HTML |
| 数据汇总 | `output/数据/data_YYYYMMDD.xlsx` | 11 Sheet原始数据 |
| 运行日志 | `logs/run_YYYYMMDD_HHMMSS.log` | 逐步执行记录 |

用浏览器打开 HTML 看板即可查看。

## 运行测试

```bash
python -m pytest tests/ -v
```

## 故障排查

| 问题 | 解决方案 |
|------|----------|
| 找不到 pandas | 运行 `pip install -r requirements.txt` |
| 预检失败 | 检查 data/raw/ 下是否放入了原始 Excel |
| 白名单匹配率低 | 检查 data/raw/客户名单/ 和 data/mappings/客户名单/ |
| 年基线未就绪 | 检查往年数据是否放入，确认时间配置正确 |
| 输出为空 | 查看 logs/ 日志文件定位问题 |
