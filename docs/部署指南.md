# 部署指南

## 环境要求

- **内置运行时优先（推荐，免安装）**：`runtime/` 目录已内置 Python 3.12 + 全部依赖（pandas/openpyxl/xlrd），**无需安装任何环境**，解压即用
- 操作系统：Windows x64
- 开发/重建运行时才需要：Python 3.12+（推荐 Conda 环境 `visual-dashboard-system`）
- 依赖：`pandas` / `openpyxl` / `xlrd` / `pytest`（见 `requirements.txt`）

> 关联文档：[数据系统设计](数据系统设计.md)（内部实现）· [字段映射](字段映射.md)（字段↔列名对照）· [维护指南](维护指南.md)（日常维护）

## 一、安装步骤

### 1. 解压文件（无需安装任何环境）

将 `Visual-Dashboard-System_vYYYYMMDD.zip` 解压到任意目录（建议目录名不含中文，避免路径编码问题）。

解压后即可使用，**不需要安装 Python、不需要 pip install**——`runtime/` 已内置全部运行环境。

## 二、配置（推荐用 Excel 编辑器）

### 配置编辑器 `config/配置编辑器.xlsx`

**推荐方式**：直接用 Excel 打开 `config/配置编辑器.xlsx` 修改，保存后运行 `run_all.bat` 自动同步生效。共 6 个 Sheet：

| Sheet | 修改内容 | 示例 |
|-------|---------|------|
| **时间配置** | 年度/月度/季度/年基线时间范围 + **结算模式** | 月度数据 → `2026-09-01 ~ 2026-09-30`；结算模式 → `月底结算` / `常规` |
| **展示规则** | 各页面的显示/最大行数/排序/优先展示/客户筛选 | 年度达成 → `客户矩阵.优先展示.1` = 比亚迪汽车工业 |
| **KPI指标** | Hero 圆环指标总数（万元，留空=按指标文件合计） | 年度达成/收入 → `50000`（=5亿） |
| **销售归属** | 母公司→子公司→指标→部门→销售→比例（120 母公司 → 580 子公司） | 科技公司 → 子公司 → 检测 → 王海龙 → 比例 1 |
| **字段映射** | 清洗时「标准字段 ← 源文件列名」的候选列名（33 行） | 财务端/收入/金额 → 候选填 `不含税收入` 即可适配源表改名 |
| **说明** | 使用指南 | — |

**关键概念**：
- **`config/配置编辑器.xlsx` 是唯一编辑入口（事实源）**；JSON 是运行时生成物，**每次运行都会按 Excel 重写**
- ⚠️ **不要直接改 JSON**：下次运行会被 Excel 里的值覆盖（要改配置请改 Excel）
- **运行顺序（固定，勿颠倒）**：配置同步（Excel→JSON）→ 年基线 → 清洗 → 拆分 → 渲染 → 汇总 → 验证
- `run_all.bat` 与图形控制台【运行全流程】走**同一条链路**（`main.py`），配置同步是第 1 步、自动执行
- 只做配置同步：`python main.py --step=config`（等价 `python scripts/config_excel_to_json.py`）
- **源文件列名变化**（清洗报 `未找到匹配列`）：直接改「字段映射」sheet 的候选列名即可，无需动 JSON/代码
  - 「当前命中(只读)」列显示上次清洗实际命中的列，写回时被忽略，仅供参考
  - 只刷新该 sheet（保留其他 sheet）：`python scripts/config_excel_to_json.py --init-map`
  - 写回后 `cleaning_config.json` 会统一为标准 2 空格缩进格式，旧文件自动备份到 `logs/cleaning_config.bak_*.json`

### 手动编辑 JSON（高级）

若不用 Excel，可直接改 JSON（需注意格式）：

**`config/清洗配置/cleaning_config.json`**：
- `时间范围` → 修改 `start_date` / `end_date` 到目标时间段
- `数据源` → 确认文件名与 Sheet 名匹配

**`config/前端渲染/展示规则.json`**：
- 控制各页面客户筛选、排序、最大行数、优先展示

## 三、运行

### Windows 用户 — 双击运行（推荐）

**方式一：图形化控制台（推荐）** — 双击根目录 `启动系统.bat`，等状态卡与数据清单加载完成后点【运行全流程】；界面实时显示 7 阶段进度、日志与产物清单。

**方式二：命令行** — 双击 `run_all.bat`（优先使用 `runtime/` 内置 Python，**无需安装任何环境**），自动执行 7 步：
```
⓪ 配置预扫描  扫描「广东自有客户」应自动归入的公司（法人=广东汽车检测中心 且无销售归属）→ 写回 配置编辑器.xlsx
① 配置同步    配置编辑器.xlsx → JSON（时间/结算模式/展示规则/KPI/销售归属）
② Phase 0    年基线清洗（往年收入/回款）
③ Phase 1+2  收入/回款清洗（按结算模式：月底结算=仅运营端 / 常规=财务端+运营端）
④ Phase 3    销售拆分（比亚迪override/比例拆分/跨父组法人选组 等，引擎层完成）
⑤ Phase 4    渲染 6 页看板 + 16-sheet 数据总表
⑥ Phase 5    生成销售完成度汇总表（output/销售完成度/）
⑦ Phase 6    看板质量验证（JS语法/onclick函数）
```

> **结算模式**（配置编辑器「时间配置」→ 结算模式）：
> - `月底结算`：运营端=完整年度累计(含当月) → 当年累计/季度累计**仅用运营端**，不叠加财务端（避免当月重复）
> - `常规`：当年累计/季度累计 = 财务端(当月) + 运营端
> - 两种模式下**月数据只用财务端当月**（月度达成页）

### 命令行运行

```bash
# 全流程（推荐）
python main.py

# 预检（检查配置和数据是否齐全）
python main.py --dry-run

# 分步执行
python main.py --step=yearly    # 仅年基线清洗
python main.py --step=clean     # 仅收入/回款清洗
python main.py --step=split     # 仅销售拆分
python main.py --step=render    # 仅渲染看板

# 仅处理某类数据
python main.py --type=收入
python main.py --type=回款

# 失败重试
python main.py --from=clean     # 从清洗步骤开始
python main.py --list           # 列出所有步骤
```

## 七、VirtualBox 干净环境验收（Windows 客户机）

> **目的**：交付前在**干净 Windows 客户机**（未安装 Python / Conda / Office）中验证免安装包能否"解压即用"。
> 与开发机不同，虚拟机内 `runtime/` 是唯一的 Python 来源，能提前暴露"依赖漏打包 / 硬编码本机路径 / 中文与空格路径"等问题。

### 1. 虚拟机准备（宿主机操作）

| 项目 | 建议值 | 说明 |
|------|--------|------|
| VirtualBox | 7.x | 宿主机为 Windows 时直接使用 |
| 客户机类型 | Microsoft Windows → Windows 10/11 (64-bit) | 仅支持 x64（32 位 Windows 不兼容 `runtime/`） |
| 内存 | 8 GB（最低 4 GB） | 清洗 + Excel 总表渲染较吃内存 |
| 处理器 | 2 核以上 | — |
| 磁盘 | 动态分配 ≥ 20 GB | 交付包 ~47 MB，产物约 25 MB |
| Guest Additions | **必装** | 设备 → 安装增强功能；提供共享文件夹 / 剪贴板 / 自动分辨率 |

装完后建议设置：**设备 → 共享剪贴板 → 双向**、**视图 → 自动调整显示尺寸**。

### 2. 把交付包送进客户机

**方式 A — 共享文件夹（推荐，稳定）**

1. 宿主机：**设备 → 共享文件夹 → 添加**，选择存放 zip 的目录，共享名用纯英文（如 `share`），勾选「自动挂载」
2. 客户机：资源管理器地址栏输入 `\\vboxsvr\share`，即可看到 zip
3. **先把 zip 复制到客户机本地磁盘，再解压**，例如 `C:\VDS\`

> ⚠️ 不要在 `\\vboxsvr\...`（网络盘）里直接解压运行：`runtime\python.exe` 从网络路径启动、文件占用、临时目录、中文/空格路径都可能造成莫名失败。

**方式 B — 拖放 / 剪贴板（需 Guest Additions）**：从宿主机直接拖 zip 进客户机（开关：设备 → 拖放 → 双向）。

**方式 C — 命令行拷贝（无界面 / 批量）**

```bat
REM 宿主机执行；<VM名称> 为 VirtualBox 中的虚拟机名（含客户机账号密码，注意脱敏）
VBoxManage guestcontrol "<VM名称>" copyto ^
  --username <客户机用户名> --password <客户机密码> ^
  "<宿主机路径>\Visual-Dashboard-System_vYYYYMMDD.zip" "C:\VDS\"
```

### 3. 验收步骤（客户机内）

1. **确认环境干净**（验收关键）：命令提示符执行 `where python` → 无输出 / 提示"找不到文件"即为干净环境；同时确认未安装 Conda 或 Microsoft Store 版 Python
2. 解压 zip 到**短英文路径**：`C:\VDS\Visual-Dashboard-System\`（避免中文与空格）
3. 放入一期真实数据：`data\raw\`（财务端 / 运营端 / 客户名单 / 往年）+ `data\sheets\手动维护\` 6 张指标表
   - 也可先做「空跑验收」：不放数据直接运行，只要不报环境类错误即可
4. 运行（二选一）：
   - 图形控制台（推荐）：双击 `启动系统.bat` → 等状态卡/数据清单加载完成 → 点【运行全流程】
   - 命令行：双击 `run_all.bat`
5. 核对产物（见「四、输出」）：`output\看板\看板_YYYYMMDD.html`、`output\数据\data_YYYYMMDD.xlsx`、`output\销售完成度\销售完成度汇总_YYYYMMDD.xlsx`、`logs\run_*.log`
6. 双击 HTML，用客户机默认浏览器逐页切换 6 页（数据总览 / 年度达成 / 年度同比 / 季度达成 / 月度达成 / 销售达成）

### 4. 验收检查清单

| 检查项 | 通过标准 |
|--------|----------|
| 环境免安装 | `where python` 为空；全程未 `pip install`、未装 Python |
| 退出码 | `run_all.bat` / 控制台显示 exit code = 0 |
| 步骤完整性 | 7 步全部完成（配置同步 → 年基线 → 清洗 → 拆分 → 渲染 → 销售完成度 → 验证） |
| 看板可用 | HTML 本地双击打开，6 页切换正常、图表渲染、弹窗 / 抽屉生效 |
| 数据总表 | `data_YYYYMMDD.xlsx` Sheet 数正确（16） |
| 无路径依赖 | 日志中不出现宿主机的 `F:\...` 等绝对路径 |
| 稳定性 | 控制台运行期间**不闪退**；`logs\launcher_error.log` 无新增异常 |

### 5. VirtualBox 环境专属问题

| 现象 | 原因 / 解决 |
|------|-------------|
| `\\vboxsvr\share` 打不开 | 未装 Guest Additions，或共享文件夹未添加 / 未自动挂载；重新添加并勾选「自动挂载」 |
| 报错找不到 `runtime\python.exe` | 在共享文件夹（网络路径）里直接运行 → 复制到客户机本地磁盘后重新解压运行 |
| 运行卡住 / 极慢 | 内存不足（调到 8 GB）；或仍从 `\\vboxsvr` 直接读取数据 |
| cmd 中文乱码 | 客户机「区域设置 → 非 Unicode 程序语言」设为中文；`run_all.bat` 已内置 UTF-8 环境变量 |
| 双击 `启动系统.bat` 无反应 | 查看 `logs\launcher_boot.log` 停在哪一步；确认未被安全软件拦截 `.vbs`；必要时 `Set-ExecutionPolicy -Scope Process RemoteSigned` |
| 窗口 / 看板显示不全 | 装 Guest Additions 后用「视图 → 自动调整显示尺寸」；或调低客户机显示缩放 |
| 月度 / 季度数据为空 | 客户机日期与「时间配置」范围不匹配（VirtualBox 会与宿主机自动同步时间），核对日期范围与数据实际月份 |
| 剪贴板 / 拖放无效 | 设备 → 共享剪贴板 / 拖放 → 双向（需 Guest Additions 已在客户机装完并重启） |

> **建议**：验收通过后给虚拟机**拍快照**（控制 → 生成备份），下一期交付回滚快照即可复用干净环境：
> `VBoxManage snapshot "<VM名称>" take "验收基线"`。

## 八、故障排查

| 问题 | 解决方案 |
|------|----------|
| 提示缺少运行依赖 | 确认解压包中 `runtime/` 目录完整存在；`run_all.bat` 会优先使用它，无需安装 |
| 预检失败 | 检查 `data/raw/` 下是否放入了原始 Excel |
| 改了 Excel 配置没生效 | 确认已保存 Excel（Ctrl+S）；`run_all.bat` 与 `python main.py` **都会**自动同步（配置同步是第 1 步）；若只想同步配置：`python main.py --step=config` |
| 直接改了 JSON，重跑后被打回 | 预期行为：`配置编辑器.xlsx` 是唯一事实源，每次运行会按 Excel 重写 JSON。要持久化请改 Excel（或运行 `python main.py --no-config` 跳过同步） |
| 配置同步失败 | 检查 `config/配置编辑器.xlsx` 中日期格式/模式/比例是否合法（生成器会拒绝写回） |
| 白名单匹配率低 | 检查 `data/raw/客户名单/` 和 `data/mappings/客户名单/` |
| 年基线未就绪 | 检查往年数据是否放入，确认时间配置（年份/月份范围）正确 |
| 月度/季度/年度数据为空 | 确认「时间配置」的日期范围与数据实际月份匹配 |
| 输出为空 | 查看 `logs/` 日志文件定位问题 |
