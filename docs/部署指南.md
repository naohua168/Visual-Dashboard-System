# 部署指南

## 环境要求

- **Python 3.12+**（推荐使用 Conda 环境 `visual-dashboard-system`）
- 操作系统：Windows（推荐） / macOS / Linux
- 依赖：`pandas` / `openpyxl` / `xlrd` / `pytest`

## 一、安装步骤

### 1. 解压文件

将 `Visual-Dashboard-System_vYYYYMMDD.zip` 解压到任意目录，**目录名不含中文**（避免路径编码问题）。

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 准备数据

将原始 Excel 放入对应目录（`data/raw/` 下）：

```
data/raw/
├── 财务端数据/
│   ├── 收入.xlsx        # 财务端收入（当月单月）
│   ├── 回款.xlsx        # 财务端回款（当月单月）
│   ├── 广东公司.xlsx    # 广东子公司（万元，可选）
│   └── 湖南公司.xlsx    # 湖南子公司（万元，可选）
├── 运营端数据/
│   ├── 收入.xls         # 运营端收入（当年累计）
│   └── 回款.xls         # 运营端回款（当年累计）
├── 往年收入数据/
│   └── 往年年收入.xlsx  # 同比基线（去年）
├── 往年回款数据/
│   └── 往年年回款.xlsx  # 同比基线（去年）
└── 客户名单/
    └── 客户名单.xlsx    # 白名单（471 家标准客户名）
```

映射 JSON（首次运行自动生成，通常无需手动创建）：

```

├── 部门事业部映射/
│   └── 部门事业部映射.json
└── 客户名单/
    └── 客户名单.json    # ← 系统自动从 Excel 生成
```

手工指标表（需手动维护）：

```

├── 年度收入总指标/年度收入总指标.xlsx
```

## 二、配置（推荐用 Excel 编辑器）

### 配置编辑器 `config/配置编辑器.xlsx`

**推荐方式**：直接用 Excel 打开 `config/配置编辑器.xlsx` 修改，保存后运行 `run_all.bat` 自动同步生效。共 4 个 Sheet：

| Sheet | 修改内容 | 示例 |
|-------|---------|------|
| **时间配置** | 年度/月度/季度/年基线时间范围 | 月度数据 → `2026-08-01 ~ 2026-08-31` |
| **展示规则** | 各页面的显示/最大行数/排序/优先展示/客户筛选 | 年度达成 → `客户矩阵.优先展示.1` = 比亚迪汽车工业 |
| **销售归属** | 母公司→子公司→指标→部门→销售→比例 | 广州小鹏 → 检测 → 饶彧 → 比例 1 |
| **说明** | 使用指南 | — |

**关键概念**：
- Excel 是「编辑层」，JSON 是「事实源」。系统运行时只读 JSON
- `run_all.bat` 启动时**自动同步** Excel → JSON（无需手动运行）
- 手动同步命令：`python scripts/config_excel_to_json.py`

### 手动编辑 JSON（高级）

若不用 Excel，可直接改 JSON（需注意格式）：

**`config/清洗配置/cleaning_config.json`**：
- `时间范围` → 修改 `start_date` / `end_date` 到目标时间段
- `数据源` → 确认文件名与 Sheet 名匹配

**`config/前端渲染/展示规则.json`**：
- 控制各页面客户筛选、排序、最大行数、优先展示

## 三、运行

### Windows 用户 — 双击运行（推荐）

直接双击 `run_all.bat`，自动执行：
```
预检 → 配置同步(Excel→JSON) → Phase 0 年基线 → Phase 1+2 收入/回款
→ Phase 3 销售拆分 → Phase 4 渲染看板 → Phase 5 看板验证 → 输出汇总
```

### 命令行运行

```bash
# 全流程（推荐）
python main.py

# 预检（检查配置和数据是否齐全）
python main.py --dry-run

# 分步执行
python main.py --step=yearly    # 仅年基线清洗
python main.py --step=clean     # 仅收入/回款清洗
python main.py --step=split     # 仅销售拆分
python main.py --step=render    # 仅渲染看板

# 仅处理某类数据
python main.py --type=收入
python main.py --type=回款

# 失败重试
python main.py --from=clean     # 从清洗步骤开始
python main.py --list           # 列出所有步骤
```

### 工具脚本

```bash
# 配置同步（Excel → JSON）
python scripts/config_excel_to_json.py             # 写回
python scripts/config_excel_to_json.py --init      # 重新生成 Excel 模板
python scripts/config_excel_to_json.py --dry-run   # 预览不改写

# 看板验证（JS语法/onclick函数/页面模板）
python scripts/verify_dashboard.py
```

## 五、更新数据操作清单

每次拿到新一期 Excel：

1. **替换文件** → `data/raw/` 下对应 Excel（文件名保持不变）
2. **更新指标** → `data/sheets/手动维护/` 下 6 张表（列结构不变，改数值）
3. **修改时间** → `config/配置编辑器.xlsx` → 「时间配置」sheet（保存即可）
4. **运行** → 双击 `run_all.bat`
5. **查看** → `output/看板/看板_YYYYMMDD.html`

## 七、故障排查

| 问题 | 解决方案 |
|------|----------|
| 找不到 pandas | 运行 `pip install -r requirements.txt` |
| 预检失败 | 检查 `data/raw/` 下是否放入了原始 Excel |
| 改了 Excel 配置没生效 | 确认已保存 Excel（Ctrl+S）；`run_all.bat` 会自动同步；若直接 `python main.py` 需先手动运行生成器 |
| 配置同步失败 | 检查 `config/配置编辑器.xlsx` 中日期格式/模式/比例是否合法（生成器会拒绝写回） |
| 白名单匹配率低 | 检查 `data/raw/客户名单/` 和 `data/mappings/客户名单/` |
| 年基线未就绪 | 检查往年数据是否放入，确认时间配置（年份/月份范围）正确 |
| 月度/季度/年度数据为空 | 确认「时间配置」的日期范围与数据实际月份匹配 |
| 输出为空 | 查看 `logs/` 日志文件定位问题 |
