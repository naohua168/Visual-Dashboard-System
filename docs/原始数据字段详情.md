## 四、数据时间层级关系

以当前数据（2026年6月）为例：

```
时间线    1-4月          5月          6月
          ├──────────────┼──────────────┤
运营端收入  554行(合计)     142行         —
运营端回款  737行(合计)     363行         —
财务端收入    —              —         1,359行
财务端回款    —              —         1,047行
广东/湖南    —       含2025-07~2026-06累计 —
```

### 时间字段值说明

- **"1-4月"**：代表1月到4月的**合计数据**，不按月份拆分
- **"5月"**：代表5月单月数据
- **具体日期**（财务端）：精确到秒的时间戳

### 输出层级

| 输出 | 数据组合 | 用途 |
|---|---|---|
| 月数据 | 仅财务端（当月） | 月度达成分析 |
| 当年累计 | 财务端 + 运营端 | 年度累计达成分析 |
