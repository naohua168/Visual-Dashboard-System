# 数据清洗展示逻辑

> 版本：v1.0 | 更新：2026-08-28
> 本文档完整梳理系统**从原始 Excel 到 6 页看板**的每一条数据清洗、聚合、展示逻辑。
> 前置阅读：[数据系统设计.md](数据系统设计.md)（结构/字段）、[字段映射.md](字段映射.md)（列名对照）。

---

## 〇、数据链路总览

```
原始 Excel（data/raw/，用户维护）
   │
   ▼  Phase 0: 年基线清洗（engine/yearly_baseline/）
往年收入/回款 → 往年收入/往年回款（6列：事业部/金额/客户/法人主体/日期/金额_万）
   │
   ▼  Phase 1+2: 收入/回款清洗（engine/income_payment/）
财务端（当月）+ 运营端（当年累计）→ 三路输出：
   ├─ 月收入/月回款        （仅财务端当月）
   ├─ 季度累计收入/回款      （财务端 + 运营端当季）
   └─ 当年累计收入/回款      （财务端 + 运营端全量）★ 主要数据源
   │
   ▼  Phase 3: 销售拆分（engine/sales/）
当年累计 → 销售收入/销售回款（7列：+销售/母公司，比亚迪法人拆分，待确认标记）
   │
   ▼  Phase 4: 渲染看板（processors/）
data_loader 加载 → page_data 六路 prepare → 6 页 HTML + Excel 总表
```

**核心口径**：
- **单位链路**：清洗引擎统一输出「元」→ `_add_wan()` ÷10000 → 「万元」→ `fmt_wan()` 千分位（全局 `.0f` 无小数点）
- **聚合链路**：`_consolidate_customers()`（子公司→母公司）→ `_group_by_parent()`（pivot 归拢）→ `_sorted_customers()`（筛选/排序/截断）
- **法人过滤**：`filter_gd_by_legal()`（广东自有客户组多组子公司按法人重映射）

## 一、清洗引擎（Phase 0-3）

### 1.1 Phase 0：年基线清洗

| 项 | 说明 |
|----|------|
| 输入 | `data/raw/往年收入数据/往年年收入.xlsx`、`往年回款数据/往年年回款.xlsx` |
| 处理 | 列重命名（收入/到款→金额）、事业部映射、法人主体简称→全称、金额转数值、日期统一赋 `年份-01-01` |
| 输出 | `data/sheets/系统数据清理/往年收入/往年收入.xlsx`、`往年回款/` |
| 粒度 | **子公司粒度**（保留每家公司独立行，未按母公司聚合）|

### 1.2 Phase 1+2：收入/回款清洗（三路输出）

**财务端**（5 来源：收入/回款/广东公司/湖南公司/南方韶关）：
1. 列名提取（按候选列名优先级匹配）
2. 日期筛选（时间范围）
3. 排除内部交易
4. 金额保留原始值（广东/湖南/韶关自动 ×10000 万元→元）
5. 事业部分类（回款版映射含详细名+全名）
6. **过客户白名单**（仅名单内客户保留）

**运营端**（收入/回款 .xls）：
1. 列名提取
2. 内部交易过滤
3. 金额保留原始值
4. 事业部分类（收入版 4 条映射）
5. 日期赋值（支持"1-4月"/"5月"特有格式，取末月）
6. **全量保留不过白名单**

**三路合并输出**：
| 输出 | 数据来源 |
|------|----------|
| 月收入/月回款 | 仅财务端（当月） |
| 季度累计收入/回款 | 财务端 + 运营端按季度范围筛选 |
| 当年累计收入/回款 | 财务端 + 运营端按年度范围筛选 |

### 1.3 Phase 3：销售拆分

1. **加载归属**：`客户销售归属.json` → `{客户: {父组: {收入/回款: {部门: {销售: 比例}}}}}`（560 条映射）
2. **逐行拆分**：
   - 查客户映射（可能多个父组）
   - 多父组时按**法人主体**选父组（`_select_parent_group`：法人=广东汽车检测中心→广东自有客户，否则→优先零部件客户）
   - 按部门销售比例拆分金额
   - 无比例 → 标记"待确认"
3. **比亚迪法人拆分**（`_apply_byd_sales_override`）：重名子公司按法人主体——**广东汽车检测中心→黄浩浩，非广东→周涵林**（含比亚迪汽车工业有限公司本部、比亚迪半导体）
4. **总额校验**：拆分前后总额一致
5. 输出：`销售收入.xlsx` / `销售回款.xlsx`（7 列：事业部/金额/客户/法人主体/日期/销售/母公司）

## 二、渲染层通用逻辑

### 2.1 数据加载（data_loader.py）

| 数据 | 来源 |
|------|------|
| income / payment | 当年累计收入 / 当年累计回款（清洗后全量）|
| sales_income / sales_payment | 销售收入 / 销售回款（拆分后 7 列）|
| quarterly_income / quarterly_payment | 季度累计（清洗后）|
| monthly_income_detail / monthly_payment_detail | 月收入 / 月回款（清洗后）|
| annual/quarterly/monthly 指标表 | `data/sheets/手动维护/` 6 张表 |
| yearly_income / yearly_payment | 往年基线（Phase 0 输出）|

### 2.2 客户聚合（page_data_utils.py）

**`_consolidate_customers(df)`** — 子公司名替换为母公司名：
- **3+ 子公司**（某母公司名下出现 ≥3 家）→ 聚合到母公司名
- **客户名本身就是母公司名** → 聚合
- **1:1 自引用**（子公司名=母公司名）→ 跳过，不映射
- **销售拆分母公司**（科技公司）→ 强制聚合，映射为 `母公司·销售` 键
- 开头调用 `filter_gd_by_legal()`（广东自有客户组多组子公司按法人重映射）

**`_group_by_parent(piv, tgt, customers, base_dir)`** — pivot 层面归拢：
- 按 `_build_cust_parent_map()`（子公司→母公司）重映射 index
- `sort=False` 保留指标表行序
- 返回归拢后的 pivot + 去重后的母公司客户列表

**`_sorted_customers(tgt, filt, piv, base_dir)`** — 客户筛选/排序/截断：
- 指标客户（指标>0）按指标表行序收录 → 非指标但有实际 → 追加末尾
- 优先展示母公司无论如何都展示
- 排序：有优先配置→按目标/实际金额降序；无→保持指标表原始顺序
- 截断：max_rows；**销售拆分键（科技公司·王海龙/李巍）不被截断**；被截断的进 rest（"查看全部"）
- 返回 `(top_customers, rest_customers)`

**`filter_gd_by_legal(df)`** — 广东自有客户法人过滤：
- 多组配置子公司（广东自有 ∩ 其他组，如广州因特检测）：
  - 法人=广东汽车检测中心 → 保留（归广东自有客户）
  - 法人≠广东 → **客户名重映射为其其他父组**（优先零部件客户/福建市场）
- 仅广东自有配置的子公司 → 无论法人都保留
- 目的：同比/年度/月度/季度页口径与销售拆分引擎一致

### 2.3 目标聚合（_consolidate_target）

- 指标表（客户+销售+4事业部列）→ 按 (客户,销售) 聚合部门指标
- 复用 `_consolidate_customers` 子公司→母公司映射
- 重叠客户（同子公司归属多父组）按 (客户,销售) 归组

## 三、6 个页面各自逻辑

### 3.1 数据总览（prepare_overview_data）

**数据源**：income/payment（当年累计）+ sales_income/sales_payment（拆分后）+ 年度指标表

| 模块 | 逻辑 |
|------|------|
| **Hero 双环** | 收入/回款实际=当年累计汇总；目标=`_kpi_target(年度达成, 收入/回款)`（配置 KPI 覆盖优先，否则指标表合计）|
| **同比** | `_yoy_from_yearly(require_month_granularity=True)`：需月份粒度，基线无粒度→不显示 |
| **部门矩阵** | 4 部门实际（df_inc/df_pay 按事业部汇总）+ 目标（年度收入指标表按部门列）+ 完成度（实际/目标）|
| **销售 TopN** | sales_income/sales_payment 按销售聚合实际；销售目标=年度指标表按销售合计；`销售TopN` 配置控制显示数量，按达成率降序 |

### 3.2 年度达成（prepare_annual_data）

**数据源**：income/payment（当年累计）+ 年度指标表

| 模块 | 逻辑 |
|------|------|
| **Hero** | 实际=当年累计全部；目标=年度 KPI 覆盖（默认指标表合计）|
| **部门卡** | 4 部门实际/目标/完成度（隐藏可展开）|
| **客户矩阵** | `_customer_pivot`（客户×事业部 pivot + 指标表分组）；`CustomerFilter.from_config(年度达成.客户矩阵)` 筛选/排序/截断；`_group_by_parent` 归拢 |
| **同比** | `_yoy_from_yearly(require_month_granularity=False)`：无月份粒度用整年 fallback（年度口径合理）|
| **子公司弹窗** | 点击母公司名 → 左右抽屉：左侧全量子公司列表（children_map），右侧子公司×4部门实际/目标/完成度明细（`_build_subs_detail`）|

### 3.3 月度达成（prepare_monthly_data）

**数据源**：monthly_income_detail/monthly_payment_detail（**仅当月**财务端）+ 月度指标表

| 模块 | 逻辑 |
|------|------|
| **Hero** | 实际=当月合计（latest_inc/latest_pay）；目标=月度 KPI 覆盖 |
| **同比** | 与基线同月对比（基线需有月份粒度，`nunique()>1` 才计算）|
| **客户矩阵** | pivot + 月度指标表；月明细已按配置窗口过滤 → 直接汇总为当月 |
| **子公司弹窗** | 与年度相同（用 raw_inc/raw_pay 原始数据，保留子公司独立行）|

> **口径统一**：Hero 当月值 = 客户矩阵合计 = 部门卡合计（同源 df_inc）

### 3.4 季度达成（prepare_quarterly_data）

**数据源**：quarterly_income/quarterly_payment（**季度累计**）+ 季度指标表

| 模块 | 逻辑 |
|------|------|
| **Hero** | 实际=季度累计合计；目标=季度 KPI 覆盖 |
| **客户矩阵** | pivot + 季度指标表；`groupby(客户, sort=False)` 保留指标表行序 |
| **同比** | `_yoy_from_yearly(require_month_granularity=True)`：季度 vs 上年同季，基线无月份粒度→不显示 |
| **子公司弹窗** | 用 q_inc_raw/q_pay_raw 原始数据 |

> **语义**：实际=1-N月累计（Q1+Q2+部分Q3）vs 目标=Q3（7-9月）；完成度可能>100%（Q1+Q2 已提前完成 Q3 目标）

### 3.5 销售达成（prepare_sales_data）

**数据源**：sales_income/sales_payment（拆分后 7 列）+ 年度指标表

**3 个卡片**：
| 卡片 | 内容 |
|------|------|
| **卡片1** | 销售个人进度条：实际（拆分后按销售聚合）/ 目标（年度收入/回款指标按销售合计），按完成率降序 |
| **卡片2** | 销售×事业部矩阵：实际（按销售×事业部聚合）+ 目标（指标表销售×部门）|
| **卡片3** | 销售×母公司×客户矩阵：下拉选择销售 → 展示该销售名下母公司→子公司实际/目标；重叠客户按 (客户,销售) 归属父组 |

**关键细节**：
- 销售列表 = 指标表销售 ∪ 实际数据销售（0 指标销售也展示）
- 待确认：拆分未匹配客户按 (客户,事业部,法人主体) 分组，弹窗展示
- 母公司列由拆分引擎写入（重叠子公司按法人主体选父组）

### 3.6 年度同比（prepare_yoy_data）

**数据源**：income/payment（当年累计）+ yearly_income/yearly_payment（往年基线）

| 模块 | 逻辑 |
|------|------|
| **KPI 大卡** | 收入/回款当年 vs 往年 + 同比%（当年-往年）/往年 |
| **部门同比表** | 4 部门当年/往年/同比（箭头 + 百分比）|
| **客户同比矩阵** | 收入/回款双 Tab；每格：当年/往年 + 同比率；**按当年累计降序排行** |

**关键细节**：
- **当年/往年都用 `_consolidate_customers` 聚合**（母公司归拢+销售拆分），粒度一致同比才有意义
- 当年/基线都过 `filter_gd_by_legal`（广东自有法人过滤）
- 基线月份筛选：汇总模式（单值）→ 全量；逐月模式 → 按 cur_months
- Top 客户列表：从年度收入指标获取（`_sorted_customers` + `_resplit_priority`），`最大行数` 截断，**销售拆分键保护**不被截断
- **"查看全部"按钮**：被截断的 rest 折叠显示，点击展开
- 无基线时降级：展示当年各部门实际数据 + 提示

## 四、关键口径速查表

| 口径 | 说明 |
|------|------|
| 财务端收入金额 | 不含税金额（元）|
| 财务端回款金额 | 应收金额（元）|
| 广东/湖南/韶关 | 万元 → ×10000 → 元 |
| 运营端 | 当年累计（含"1-N月"），全量保留 |
| 白名单 | 财务端 5 来源清洗后**均过**；运营端不过 |
| 部门映射 | 全称→简称（检测/信息/能源/海外）|
| 收入/回款三路 | 月（仅财务）/ 季度累计 / 当年累计 |
| 客户聚合 | 3+子公司聚合到母公司；1:1不聚合；拆分键强制 |
| 广东自有法人 | 法人=广东汽车检测中心→广东自有；否则→零部件等 |
| 比亚迪法人 | 广东→黄浩浩；非广东→周涵林 |
| 单位展示 | 元 ÷10000 = 万元，`.0f` 无小数点 |
| 矩阵排序 | 有优先配置→金额降序；无→指标表原始顺序 |
| 销售拆分键 | `科技公司·王海龙`(34家) / `科技公司·李巍`(98家)，不截断 |

## 五、常见问题定位

| 现象 | 可能原因 | 排查点 |
|------|----------|--------|
| 广东自有能源金额异常 | 多组子公司法人未过滤 | `filter_gd_by_legal` 是否生效 |
| 零部件客户没增加 | 广东自有过滤用了"删除"而非"重映射" | `filter_gd_by_legal` 重映射逻辑 |
| 比亚迪黄浩浩/周涵林混在一起 | 比亚迪不在 BYD_SUB_COMPANIES | `_apply_byd_sales_override` |
| 同比页往年全 0 | 基线未按当年聚合逻辑 consolidate | `prepare_yoy_data` 中 pi/pp 处理 |
| 月度同比失真 | 基线无月份粒度 | `_yoy_from_yearly` require_month_granularity |
| 完成度 >100% | 累计实际 vs 季度目标 | 季度页语义（正常）|
| 科技公司只有一位销售 | 拆分键被 max_rows 截断 | `_sorted_customers` 拆分键保护 |
| 看板缺"查看全部" | rest 为空（截断前未收集）| `_resplit_priority` 收集被截断客户 |
