# Visual Dashboard System

> 销售数据可视化看板生成系统 — 从原始 Excel 到 6 页交互式 HTML 看板的自动化流水线

---

## 快速开始

### 接收方（解压即用，无需安装任何环境）

1. 解压 `Visual-Dashboard-System_vYYYYMMDD.zip`（内置 `runtime/`，含 Python + 全部依赖）
2. 放入原始 Excel（`data/raw/`）→ 更新指标表（`data/sheets/手动维护/`）→ 改时间（`config/配置编辑器.xlsx`）
3. **双击 `run_all.bat`**，自动完成：预检 → 配置同步 → 清洗 → 拆分 → 渲染 → 验证
4. 打开 `output/看板/看板_YYYYMMDD.html` 查看看板

### 开发者 / 命令行

```bash
# 安装依赖（仅开发环境需要）
pip install -r requirements.txt

# 预检（确认数据就绪）
python main.py --dry-run

# 全流程一键运行
python main.py

# 或 Windows 双击
run_all.bat
```

### 一次性配置（三步）

1. **放数据** → 原始 Excel 放入 `data/raw/` 对应目录（文件名固定）—— 字段清单见 [数据系统设计 · 原始数据](docs/数据系统设计.md#二原始数据dataraw)
2. **维护指标** → 6 张目标表放 `data/sheets/手动维护/`（列结构：`客户/销售/检测/信息/能源/海外`，单位万元）
3. **配置时间** → 打开 `config/配置编辑器.xlsx` → 「时间配置」sheet 改日期 → 保存

### 日常运行（一步）

**双击 `run_all.bat`**，自动执行 7 个阶段：

```
① 预检        → 检查数据/配置/映射是否齐全
② 配置同步    → 配置编辑器.xlsx → JSON（改配置自动生效）
③ Phase 0    → 年基线清洗（往年数据）
④ Phase 1+2  → 收入/回款清洗（财务端当月 + 运营端当年累计）
⑤ Phase 3    → 销售拆分（4层匹配 + 总额校验）
⑥ Phase 4    → 渲染 6 页看板 + Excel 总表
⑦ Phase 5    → 看板质量验证（JS语法/函数绑定）
```

### 命令行（开发/调试）

```bash
python main.py                          # 全流程（不含配置同步）
python main.py --step=yearly            # 只年基线
python main.py --step=clean             # 只清洗 Phase 1+2
python main.py --step=split             # 只销售拆分
python main.py --step=render            # 只渲染
python main.py --type=收入              # 只收入链路
python main.py --from=clean --to=render # 区间执行
python main.py --dry-run                # 预检（不写文件）
python main.py --list                   # 列出所有步骤
```

### 工具脚本

```bash
python scripts/config_excel_to_json.py          # 配置 Excel → JSON 同步
python scripts/config_excel_to_json.py --init   # 重新生成 Excel 模板
python scripts/config_excel_to_json.py --dry-run# 预览将写回的内容
python scripts/verify_dashboard.py              # 看板质量验证
```

## 配置指南（数据更新必读）

### ⏱ 时间范围（Excel 编辑）

**推荐**：`config/配置编辑器.xlsx` → 「时间配置」sheet，保存后运行 `run_all.bat` 自动生效。

| 配置项 | 示例值 | 影响页面 |
|--------|--------|----------|
| 年度累计 | `2026-01-01 ~ 2026-08-31` | 数据总览 / 年度达成 / 销售达成 / 年度同比 |
| 月度数据 | `2026-08-01 ~ 2026-08-31` | 月度达成 |
| 季度累计 | `2026-07-01 ~ 2026-09-30` | 季度达成 |
| 年基线 | `年份: 2025, 月份: [1, 8]` | 年度同比（Phase 0） |

也可直接改 JSON：`config/清洗配置/cleaning_config.json` → `时间范围`。

### 🎨 展示规则（Excel 编辑）

**推荐**：`config/配置编辑器.xlsx` → 「展示规则」sheet（路径列结构）。

| 配置项 | 说明 |
|--------|------|
| `客户矩阵.优先展示.1` | 填母公司组名或客户名，始终排在前面 |
| `客户矩阵.最大行数` | `0` = 全部显示；`>0` = 截断 |
| `客户矩阵.排序` | `目标合计降序` / `实际金额降序` / `达成率降序`；**未配置优先展示时按指标表原始顺序展示** |
| `数据总览.销售TopN` | 数据总览/销售页显示的最大销售人数 |
| `部门卡.显示` | `true` / `false` |

也可直接改 JSON：`config/前端渲染/展示规则.json`。

### 📊 KPI 指标总数（Excel 编辑）

**推荐**：`config/配置编辑器.xlsx` → 「KPI指标」sheet（单独 sheet，控制 Hero 圆环的指标总数）。

| 列 | 说明 |
|----|------|
| 页面 | `年度达成` / `月度达成` / `季度达成` |
| 指标 | `收入` / `回款` |
| 值(万元) | **留空 = 不覆盖**（按指标文件合计，现状）；**填数字 = 覆盖** KPI 卡片显示 |

- 只影响 KPI 卡片（Hero 圆环）的指标总数，**不影响表格/矩阵/部门卡明细指标**
- 数据总览页的年度 KPI 跟随「年度达成」的设置
- 也可直接改 JSON：`config/前端渲染/展示规则.json` 各页面的 `KPI指标` 区块

### 👥 销售归属（Excel 编辑）

**推荐**：`config/配置编辑器.xlsx` → 「销售归属」sheet（母公司→子公司→指标→部门→销售→比例，~2340 行）。

也可直接改 JSON：`config/清洗配置/客户销售归属.json`。

> **机制**：Excel 是「编辑层」，JSON 是「事实源」。`run_all.bat` 自动同步；`python main.py` 不读 Excel。

## 使用流程

### 1. 运行

```bash
# 一键（推荐）
run_all.bat

# 全流程
python main.py
python main.py --dry-run                # 预检（不写文件）
python main.py --list                   # 列出所有步骤

# 分步
python main.py --step=yearly            # 只年基线
python main.py --step=clean             # 只清洗 Phase 1+2
python main.py --step=split             # 只销售拆分
python main.py --step=render            # 只渲染
python main.py --type=收入              # 只收入链路
python main.py --from=clean --to=render # 区间执行

# 调试用（等价于对应 step）
python -m engine.yearly_baseline.run
python -m engine.income_payment.run --type=收入
python -m engine.sales.run
python -m processors.run
```

### 2. 获取结果
- `output/看板/看板_YYYYMMDD.html` — 6 页可视化看板
- `output/数据/data_YYYYMMDD.xlsx` — 16 Sheet 数据总表（每个 sheet 名称与 `data/sheets/` 下文件夹名称一致）

### 3. 运行测试

```bash
python -m pytest tests/ -v              # 147 passed
python -m pytest tests/ -k "splitter"   # 按关键字
```

## 4-Phase 流水线

```
Phase 0: 年基线清洗  →  往年收入/回款数据 → 往年收入/回款（6列标准表）
Phase 1+2: 收入/回款  →  财务端(当月) + 运营端(当年累计) → 三路输出（月/季度累计/当年累计）
Phase 3: 销售拆分    →  4层匹配 + 总额校验 → 销售收入/回款（7列，含销售）
Phase 4: 渲染看板    →  6页HTML + Excel总表 → output/
```

## 核心设计

| 设计 | 说明 |
|------|------|
| 配置驱动 | 清洗参数全在 `cleaning_config.json`，页面/配色全在配置，改日期/列名不需改代码 |
| Excel 配置 | `配置编辑器.xlsx` 是编辑层（时间/展示规则/KPI指标/销售归属），`run_all.bat` 自动同步 JSON |
| 列名映射 | 每个字段多个备选列名按序尝试；**回款用应收金额、收入用不含税金额** |
| 单位转化 | 清洗引擎统一输出"元" → 广东/湖南 ×10000 → 渲染层 ÷10000 → "万元" → `fmt_wan()` 千分位 |
| 客户归拢 | 3+ 子公司自动聚合到母公司名；1:1 关系不聚合；拆分母公司强制按销售拆分 |
| 销售拆分 | 科技公司 → `科技公司·王海龙(34家)` / `科技公司·李巍(98家)`；仅统计该销售名下子公司的实际/目标，两销售相加=全部 |
| 矩阵排序 | 未配置「优先展示」时按**指标表原始顺序**展示聚合后的公司；配置后按目标/实际金额降序 |
| 子公司弹窗 | 点击母公司名 → 左右两侧滑入抽屉（左侧子公司列表、右侧×4部门明细），点击左侧项联动右侧滚动高亮 |
| 全局 .0f | 金额统一按万元取整无小数点 |
| 销售归属 | 125 母公司 → 577 子公司 → 收入/回款 → 4部门 → 销售 → 比例；未匹配标记"待确认" |
| 比亚迪拆分 | 重名子公司按法人主体分配（广东→黄浩浩，非广东→周涵林） |
| 客户白名单 | 财务端 5 来源清洗后**均过客户白名单**；运营端全量保留不过名单 |
| 数据锁定 | `data/sheets/手动维护/` 6 张指标表数据锁定，仅用户手动维护，AI 不自动修改 |
| 图表本地化 | Chart.js 内联进 HTML（`processors/static/chart.umd.min.js`），离线可用，CDN 兜底 |
| Lucide 图标 | 统一内联 SVG 图标库（`processors/static/icons.py`），零外部依赖 |
